# 역할
수집 전용 Electron 앱. 바탕화면의 우주 비행사 캐릭터에 끌어다 놓거나 메뉴로 기록을 넣는다.
열람·검색·챗봇은 만들지 않는다 (웹 담당).

# 프로세스 구분
- main: OS 연동. 항상 위에 뜨는 창, 화면 캡처, 파일 읽기, 로그인용 임시 서버
- preload: main과 renderer를 잇는 통로. renderer는 preload가 노출한 API만 사용
- renderer: 화면. Node.js API를 직접 쓰지 말 것
- IPC 채널 이름은 한 파일에서만 정의 (파일 위치는 빌드 도구를 정한 뒤 결정)

# 로그인 (로컬 주소로 돌려받기 + PKCE)
1. 앱이 127.0.0.1의 임의 포트에 임시 서버를 연다
2. 브라우저로 웹 로그인 페이지를 연다
3. 웹에서 로그인 성공 → http://127.0.0.1:포트/callback?code=일회용코드 로 이동
4. 앱이 코드와 PKCE 검증값을 서버에 보내 토큰으로 바꾸고, 임시 서버를 닫는다
- PKCE 검증값(verifier)은 앱 메모리에만 두고 로그에 남기지 말 것
- 임시 서버는 127.0.0.1에만 열 것 (0.0.0.0 금지)

# 수집 규칙
- 저장은 packages/shared의 수집 함수만 사용 (업로드 코드를 앱에 따로 쓰지 말 것)
- 끌어다 놓기
  - 브라우저 주소(주소창의 사이트 아이콘, 페이지 안의 링크): URL 기록 (유튜브 등은 영상 링크)
  - 웹페이지 이미지, 바탕화면 파일: 파일 기록
- 메뉴 (캐릭터를 누르면 열림): 클립보드 붙여넣기, 메모, 화면 캡처, 파일선택, 웹 열기, 앱 종료
  - 클립보드 붙여넣기: 글은 하이라이트 기록(요약 없이 문장 그대로), 이미지는 파일 기록, 주소는 URL 기록
  - 웹 열기는 브라우저로 웹을 연다. 앱 안에 열람·검색·챗봇 화면을 만들지 말 것
- 저장 창: 놓거나 메뉴로 넣으면 그룹을 고르는 작은 저장 창을 띄운다. '분류 안 된 기록'이 선택된 채로 뜨고, 'AI 추천' 버튼, 다른 그룹 고르기, 새 그룹 만들기로 그룹을 정해 저장할 수 있다
- URL·영상 링크는 웹 주소를 기록에 저장한다. 내용 요약은 가공 서버가 한다. 원문 글과 영상 자체는 저장하지 않는다
- 저장 결과는 캐릭터 옆 말풍선으로 알린다. 상황별 문구와 사라지는 시점은 docs/spec/screens/01-desktop-collector.md의 표를 따른다
- 업로드 완료(queued)뿐 아니라 가공 완료(done)와 가공 실패(failed)도 알린다. 저장한 기록의 처리 상태를 3초마다 웹 서버 API에 묻고, done이나 failed가 되면 멈춘다. 2분이 지나면 알리지 않고 멈춘다. 이 조회 코드는 packages/shared의 수집 함수에 둔다 (Supabase 실시간 알림은 쓰지 않음)
- 저장 창의 AI 추천: 창이 열릴 때는 추천을 요청하지 않는다. 사용자가 'AI 추천' 버튼을 누를 때만 웹 서버에 추천을 요청하고, 답이 오면 선택을 추천 그룹으로 바꾼다. 기다리는 동안 버튼에 진행 표시를 하고, 실패하면 선택을 그대로 둔다
- 추천 없이 '분류 안 된 기록'으로 저장한 기록은 가공이 끝난 뒤 AI가 요약본으로 그룹을 추천하고, 사용자가 웹의 행성 상세 패널에서 수락한다. 앱은 이 단계에 관여하지 않는다
- 출처 주소(source_url)는 모든 기록에서 선택이다. 클립보드로 넣은 글의 출처 주소는 저장 창의 선택 입력 칸으로 받고, 비워도 저장한다. 클립보드에서 주소를 읽을 수 있는 경우에만 미리 채운다
- 지원 형식(csv, txt, md, jpeg, jpg, png, svg, HTML, PDF)과 10MB 제한은 올리기 전에 앱에서 먼저 검사

# 미정 — 구현 전에 사용자에게 선택지를 주고 물어볼 것
- Electron 빌드 도구 (Electron Forge, electron-vite 등)
- 포트와 PKCE 값을 웹 로그인 페이지에 넘기는 방식, 토큰 교환을 맡는 서버
- 토큰 보관 위치
- 브라우저 로그인을 끝내지 않고 닫았을 때 임시 서버 처리
- AI 추천 버튼이 부르는 API의 주소와 형식 (웹 담당과 합의. F3의 버튼 추천 처리 위치가 웹 서버로 확정되어야 함)
- AI 추천에 실패했을 때 저장 창에 보일 안내
- macOS에서 클립보드의 출처 주소를 읽을 수 있는지
