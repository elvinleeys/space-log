# SPACELOG design.md (v3 · 2026-11-28)

`docs/design/spacelog-prototype.html`, `docs/design/spacelog-login.html` 기준입니다. 다른 결과물에 그대로 옮길 수 있게 실제 값을 적었습니다. v2 대비 바뀐 곳은 **[v3]** 로 표시했습니다.

## 1. 방향

- 우주 톤의 기록 아카이브. 기본은 **다크 모드**.
- UI는 거의 보이지 않게. 기록 내용과 그룹(행성) 이미지가 주인공입니다.
- 강조색은 한 번에 하나. 화면 공통 강조는 `#0066cc`, 그룹 안에서는 그 그룹의 색.
- 보기 방식 두 가지: **List(문서 목록)** 와 **Space(우주 공간)**. **[v3]** 1D/3D → List/Space로 이름 변경.
- 네온 글로우, 패턴, 이모지, 색 있는 테두리 강조는 쓰지 않습니다.

## 4. 글자

- 서체: **Pretendard Variable** 하나. Google 로그인 버튼만 Google 규정상 Roboto 500.
- 굵기 400(본문) · 600(제목·강조). 500은 Google 버튼 외 쓰지 않음.
- 한글: `word-break: keep-all`, 긴 문단 `text-wrap: pretty`. 버튼·칩은 `white-space: nowrap`.

## 5. 배치

### 넓은 화면

```
┌ 목록 창 (좌상단) ┐   [검색 알약]   ┌ 기간 바 (우상단) ┐
│ SPACELOG    [접기]│                │ 전체 오늘 이번주 이번달 ‹ 직접 지정 › │
│ 우주선장 로그아웃 ⚙ │                └──────────────────┘
│ [ List | Space ]  │
│ 그룹 바로가기 n    │
│  + 새 그룹         │
│  그룹 …  (··· 편집) │
└──────────────────┘
              [ + 기록 넣기 ][ 물어보기 ]
```

- 목록 창: `left 24px, top 24px`, 폭 300px, 모서리 18px, 안쪽 16px. 위쪽 고정, 아래만 스크롤(스크롤바 숨김 + 64px 그라데이션 + `⌄`).
- **[v3]** 밝기(다크/브라이트) 버튼은 뺐습니다.
- 기간 바: 순서 **전체 · 오늘 · 이번 주 · 이번 달** + ‹ 직접 지정 ›. 처음 들어오면 ‘오늘’. 오늘 기록이 0개면 이번 주를 보여 주고 안내.
- 검색: List·Space 같은 자리·크기, 알약.
- 하단: ‘+ 기록 넣기’(CTA `#0066cc`)와 우주먼지 ‘물어보기’를 한 세트로 가운데 정렬, 아래 24px.
- Space에서 화면 폭 1280px 미만일 때 그룹 창이 열리면 목록 창 자동 접힘. 우주는 화면 정가운데 기준.

### 좁은 화면 (1100px 미만 = 모바일 형식) **[v3]**

- 목록 창 → 왼쪽 사이드바. 연 동안 기록 넣기·물어보기 숨김. 항상 불투명.
- 상단: 시계 아이콘을 누르면 기간 바, 검색 아이콘을 누르면 검색창.
- 기록 넣기·물어보기는 모달 대신 페이지로 엽니다. 그룹·상세 화면은 좌우·아래 여백 없이 채웁니다.
- 호버 효과 없음. ‘···’ 편집은 길게 눌러 엽니다.

## 6. List와 Space

### List
- 페이지 전체 스크롤. 상세도 창 안 스크롤 없이 길어집니다.
- 열: 체크 · 썸네일(이미지 기록은 실제 썸네일, 그 밖은 종류 아이콘) **[v3]** · 제목 · 그룹 · 넣은 날.
- 넣은 날 표기: ‘오늘’ · ‘어제’ · ‘N일 전’(2~6일) · ‘M월 D일’(7일 이상).
- 위쪽: 기록 n개 + [전체 | 그룹별] 스위치 + 그룹 이동 + 휴지통. 체크하면 ‘n개 선택’ · 선택 해제. 제목 줄 체크박스로 전체 선택.
- ‘분류되지 않은 기록’ 카드(빠른 분류)는 ‘분류 안 된 기록’ 그룹 안에서만.

### Space
- 그룹 = 행성(실사 이미지 + 색 필터). 모양: 기본, 고리, 성운, 지구, 탐사선.
- **[v3]** 그룹 썸네일(목록 창·그룹 창 제목 옆·그룹 이동 목록)은 우주에 떠 있는 모양과 같은 그림. 기본·고리·성운은 그룹 색 필터, 지구·탐사선은 원본 그대로.
- 행성 위에 그룹 이름 + 기록 n(성운은 ‘조각 n’). 앞에 있는 행성·캐릭터·창에 가려질 때만 숨김.
- 우주인 캐릭터(실사 PNG, 3등신, 방향별 이미지).
- 행성을 누르면 날아가 착륙 → 오른쪽 그룹 창, 기록을 누르면 상세. 그룹 안에서는 기록 넣기·물어보기 숨김, 검색·목록 창 50%(마우스 올리면 100%).
- 배경 음악 없음.

## 8. 그림자·블러·움직임

- 그림자 하나: `rgba(0,0,0,0.22) 3px 5px 30px`. 떠 있는 창·토스트에만.
- 블러: `backdrop-filter: saturate(180%) blur(20px)`. 떠 있는 창에만.
- 누름: 버튼·칩 `scale(0.95)`, `200ms cubic-bezier(0.25,0.1,0.25,1)`.
- 호버: 행 전체 폭. 모바일 없음.
- 포커스: `2px solid #0071e3` 2px 띄움. 검색창 포커스는 테두리 `#2997ff` + 링 `0 0 0 3px rgba(41,151,255,0.25)`.
- 로딩: 점 3개 깜빡임(1s, 0.15s 간격). 튀는 움직임 없음.

## 9. 구성 요소

- **주 버튼:** 알약, `#0066cc`(그룹 안 `base`), 흰 글자, 높이 36~48px.
- **흰 버튼(로그인·가입하기):** 알약 48px, 면 `#fff`, 글자 `#1d1d1f` 600. 진행 중엔 40% + 점 3개.
- **보조 버튼:** 알약, 투명 + 테두리 또는 `rgba(255,255,255,0.18)` 면.
- **텍스트 버튼:** 테두리 없음, `rgba(255,255,255,0.72)`, 호버 흰색. 두 개를 나란히 둘 땐 1px×12px 세로 구분선.
- **스위치(분할 알약):** List/Space, 전체/그룹별, 기간.
- **체크박스:** 16px, 끔 `1.5px solid rgba(255,255,255,0.32)`, 켬 `#0066cc`. 옆 요소와 12px 이상.
- **말풍선 팝업:** 버튼 바로 아래(모바일은 위), 꼬리 있음.
- **토스트:** 화면 아래 가운데, `bottom 76px`, 물어보기 말풍선 위로 겹침. 약 2.4초.
- **확인:** 삭제·합치기는 같은 창 안에서 한 번 더. 브라우저 확인창 쓰지 않음.

### 기록 넣기 **[v3]**
- 챗봇 창과 같은 크기의 모달, 바깥 흐림. 모바일은 페이지(메모 칸 최소 200px, 남는 높이 채움).
- **2단계 흐름 — 저장 버튼을 누르기 전에 AI 추천이 끝나 있습니다.**
  1. **파일 넣기:** 큰 점선 영역 하나(‘파일을 끌어다 놓거나 눌러서 고르세요’). 버튼 없음. 고르기·끌어다 놓기·붙여넣기(Ctrl+V) 모두 바로 다음으로. 아래 ‘파일 없이 메모로 넣기’ → 2단계로 바로(추천 없음).
  2. **추천 중 (약 1.3초):** 같은 창 안에 ✦ 아이콘 · ‘알맞은 그룹을 찾고 있어요’ · ‘파일 n개를 읽고 있어요’ · 점 3개.
  3. **확인하고 저장:** 제목 · 메모 · 파일 목록 · 그룹 선택 · 넣기. 그룹은 AI 추천 그룹이 미리 선택되고, 선택 줄과 펼친 목록의 해당 그룹에 ‘✦ AI 추천’ 뱃지(면 `rgba(255,255,255,0.1)`, 알약 22px). 다른 그룹을 고르면 선택 줄 뱃지는 사라지고 목록에는 남음.
- 2단계에서 파일을 더 넣으면 다시 추천 중을 거쳐 새로 추천.
- 글·링크를 붙여넣거나 끌어다 놓으면 메모 칸에 담고 2단계로 바로 열림. 저장은 ‘넣기’를 눌렀을 때만.
- 파일 여러 개는 **한 기록으로 묶음**. 10개 / 파일당 10MB / 합계 50MB.
- 파일은 저장 전까지 앱 안에만 둡니다(예비 데이터를 서버에 따로 두지 않음).

### 기록 상세 **[v3]**
- ← 목록으로(16px 텍스트) · ‹ n/n ›(20px, 테두리 없음) 가운데 정렬.
- 그룹 줄: ‘분류 안 된 기록 · 옮기기’ 옆 **AI 추천** 버튼 → 그룹 목록에 ‘✦ AI 추천’ 뱃지, 사용자가 골라 옮김.
- 링크: 있으면 ‘링크 열기’, 없으면 ‘링크 추가하기’. 그 아래 ‘AI 분석하기’(흰 면, 검정 글자).
- AI 분석 결과: 다시 분석 · 메모에 옮기기 · 지우기(3초 안에 두 번 눌러야 지움).
  - **다시 분석은 지난 분석 이후 메모에 새로 쓴 글자가 10자 이상일 때만** 활성.
  - AI 기록 수집이 꺼진 그룹: 버튼 비활성 + ‘AI를 활용한 기록 수집이 꺼져 있는 그룹이에요’.
- 메모: 자동 저장. 메모와 그룹 사이 32px.
- 미리보기할 데이터가 없으면 미리보기 칸 숨김. 묶음 기록은 파일 격자.

### 우주먼지 (챗봇) **[v3]**
- 흰 빛무리 원형 버튼 + ‘물어보기’. 말풍선 ‘기록을 찾아봐요’(X로 닫기).
- 탭: **FAQ · 대화 · 설정**. 닫기 X 24px, 아이콘만.
- 대화: 입력창 안 화살표 보내기 버튼. 새 대화 버튼 고정.
- 답변 아래 ‘기록으로 저장’(다시 누르면 취소). 해당하면 같은 줄에 바로가기 버튼.
  - 찾는 기록이 없고 ‘챗봇이 읽지 않을 그룹’이 있으면 ‘챗봇 설정 바로가기 →’.
- 긴 답: ‘새 창으로 보기 ↗’ → 챗봇과 같은 크기의 **요약 창**(핵심 1줄 + 요약 3개) → ‘전체 보고서 보기 ›’로 넓게, ‘‹ 요약으로’로 돌아오기. 모바일도 요약 먼저(전체 페이지). 챗봇 옆 공간이 요약 창 폭보다 좁으면 챗봇 위에 겹쳐 엶.
- FAQ: 토글로 답 펼침. 바로가기 버튼: 기록 넣기 열기 · 검색창으로 가기 · 이번 주 기록 보기 · 전체 기간으로 보기 · Space로 보기. 준비중 항목은 목록 맨 아래, 어두운 회색.
- 설정: ‘챗봇이 읽지 않을 그룹’(체크) + 다시 읽기.

### 계정 설정 (목록 창 ⚙) **[v3]**
- 맨 위: 닉네임(본문 강조) + 연필 아이콘(2~12자, ✓ 저장 · ✕ 취소) / 이메일(캡션, 회색).
- 구분선 아래: Google 로그인 줄 + 오른쪽 ‘연동하기’ 또는 ‘연동 해제’ 하나.
- 이메일이 길면 `…`로 자르고, 잘렸을 때만 `⌄`가 생겨 누르면 펼침.
- 아래 List/Space 스위치와 8px 더 띄움.

### 로그인 · 회원가입 **[v3]**
- 폭 360px(메일 보냄 화면 420px), 가운데.
- 첫 화면: Google로 계속하기(Google 규정 다크 버튼) · 이메일로 로그인 · 처음이신가요? 회원가입.
- 이메일 로그인: 이메일 · 비밀번호(눈 아이콘, ‘비밀번호를 잊었어요’) · 로그인 · ‘계정이 없나요? 회원가입 | 다른 방법으로 로그인’.
- 회원가입: 닉네임(2~12자) · 이메일 · 비밀번호(8자 이상, 영문+숫자 조건 체크) · 확인 · 약관 동의(필수) · 가입하기 · ‘이미 계정이 있나요? 로그인 | Google로 가입하기’.
- 칸 오류는 칸 아래 붉은 한 줄. 화면 단위 안내(실패·만료·로그아웃)는 맨 아래 붉은 박스, 두 줄로 끊음.
- 약관 문구 ‘계속하면 이용약관과…’는 회색.
- 로그아웃하면 로그인 페이지로 이동, 로그아웃 상태에서는 기록을 보여 주지 않음. Google로 로그인하면 Google 연동됨 상태.

## 10. 아이콘

- Lucide만: `https://unpkg.com/lucide-static@0.469.0/icons/<이름>.svg`, 12~20px.
- 다크 `filter: invert(1)` + 투명도 0.6~0.85.
- 이모지·직접 그린 그림 없음. 로고는 글자 ‘SPACELOG’.

## 11. 문구

- 차분한 해요체, 짧게. 느낌표·과장 없음.
- 버튼 1~3어절, 동작 먼저.
- 준비 안 된 기능은 ‘(준비중)’ 또는 ‘○○은 준비 중이에요.’
- 오류: 무엇이 안 됐는지 + 할 일. 예) ‘로그인하지 못했어요. 다시 시도해 주세요.’

## 12. 키보드 (Space) **[v3]**

- 방향키 ↑↓ 앞뒤, ←→ 좌우, Space 상승, Shift 하강, 드래그 시점, 휠 다가가기, E 착륙.
- Esc 한 단계씩 닫기: 상세 → 그룹 창 → 우주.
- 입력칸 포커스 중에는 비행 키를 받지 않음. 모바일에서는 ‘처음이라면 이렇게 날아요’ 안내 숨김.

## 13. 하지 말 것

- 한 화면에 강조색 두 개 이상, 카드 그림자
- 스크롤바 노출 (⌄ 로 안내)
- 이모지, 느낌표, 굵기 500(Google 버튼 제외), Pretendard 외 서체
- 화면을 오가며 위치가 흔들리는 배치
- 블랙홀 삭제, 관측소·탐사선 (P0 범위 밖)
