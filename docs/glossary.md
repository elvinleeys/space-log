# 용어

| 용어 | 뜻 | 화면 표현 |
| --- | --- | --- |
| 기록 (정보 기록) | 사용자가 저장한 정보 하나 | 별 |
| 그룹 | 기록을 묶는 단위. 이름과 색상을 가진다 | 행성 |
| 분류 안 된 기록 | 사용자마다 1개씩 있는 기본 그룹. AI 추천이 없으면 여기에 들어간다 | 성운 |
| 원래 맥락 | 저장할 때 남기는 정보를 접한 상황이나 이유. 선택 입력 | 메모 |
| 하이라이트 | 웹페이지에서 드래그해 복사한 문장. 데스크톱 앱에서는 클립보드 붙여넣기로 넣는다. 요약하지 않고 그대로 저장. 출처 주소는 있으면 함께 저장 (선택) | |
| AI 정리글 (요약본) | AI가 양식에 맞춰 정리한 기록 요약. 한 줄 요약, 핵심 포인트, 자료 유형, 이럴 때 다시 보세요 등 (docs/database.md) | |
| 이럴 때 다시 보세요 | AI 정리글에서 이 기록이 쓸모 있을 상황. 재발견의 핵심 문구 | |
| 원문 조각 | 원문을 문단 단위로 자른 조각. 벡터로만 저장하고 글은 저장하지 않는다 (URL·영상 링크) | |
| 벡터 | 글을 숫자로 바꾼 값. 비슷한 내용을 찾을 때 쓰며 Qdrant에 저장 | |
| 재발견 메모 | 기록에 날짜별로 덧붙이는 새로운 의미나 쓰임 (UI 미정) | |
| 연결 | 두 기록을 잇는 선. AI가 추천하고 사용자가 수락 (P1) | 별자리 |
| 블랙홀 | 정한 기간이 지난 기록을 모아 다시 보거나 정리하는 곳 (P1) | 블랙홀 |
| 처리 상태 | uploading, queued, processing, done, failed, deleting (삭제 중) | 형성 중인 별 등 |
| 연관 기록 | 기록 상세에서 보여 주는 비슷한 기록. 유사도 0.8 이상 상위 3개. 연결(별자리)과는 다르며 버튼 없이 링크로만 보여 준다 | |
| 수집 경로 | 기록이 들어온 곳: desktop, web, mcp | |
| 물어보기 | 내 기록 안에서만 답하는 AI 챗봇 | |
| MCP | ChatGPT, Claude 등 평소 쓰는 AI와 연결하는 방식 | |
| 시안 A, 시안 B | 사용자 테스트로 고를 웹 디자인 시안 두 가지 | |
