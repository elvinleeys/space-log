# 용어

| 용어 | 뜻 | 화면 표현 |
| --- | --- | --- |
| 기록 (정보 기록) | 사용자가 저장한 정보 하나 | 기록 (Space에서는 별 모양) |
| 그룹 | 기록을 묶는 단위. 이름, 색상(7가지), 모양(5가지)을 가진다 | 그룹 (Space에서는 행성 모양) |
| 분류 안 된 기록 | 사용자마다 1개씩 있는 기본 그룹. 처음 저장한 기록은 여기에 들어가고, 사용자가 고르거나 AI 추천을 받아 확정한 그룹으로 옮긴다 | 분류 안 된 기록 (Space에서는 성운 모양, 개수는 '조각 n') |
| 원래 맥락 | 저장할 때 남기는 정보를 접한 상황이나 이유. 선택 입력. 기록 상세에서 고치면 자동 저장 (original_context) | 메모 |
| 하이라이트 | 웹페이지에서 드래그해 복사한 문장. 데스크톱 앱에서는 클립보드 붙여넣기로 넣는다. 요약하지 않고 그대로 저장. 출처 주소는 있으면 함께 저장 (선택) | |
| AI 정리글 (요약본) | AI가 파일 내용과 메모를 함께 검토해 만든 기록 요약. 한 줄 요약 1개 + 핵심 내용 3개 (docs/database.md). 'AI 분석하기'나 챗봇 요청 때만 만든다. 수정 불가 | AI 분석 (한 줄 요약 · 핵심 내용 3개) |
| AI 분석하기 | 분석 내용이 없는 URL·영상·파일·캡처 기록에서 AI 정리글을 만드는 버튼. 누르면 사라지고, 분석에 실패하면 다시 나온다 | AI 분석하기 |
| 다시 분석 | 사용자가 메모를 직접 고쳐 마지막 분석 때와 달라졌을 때만 누를 수 있는 재분석 버튼. '메모에 옮기기'로 바뀐 것은 해당하지 않는다 | 다시 분석 |
| 메모에 옮기기 | AI 분석의 핵심 내용 3개를 메모 끝에 덧붙이는 버튼. 같은 분석은 한 번만 | 메모에 옮기기 |
| 분석 상태 | AI 분석 진행: none, analyzing, done, failed (analysis_status). 처리 상태와 별개 | 로딩 표시 등 |
| 원문 조각 | 원문을 문단 단위로 자른 조각. 벡터로만 저장하고 글은 저장하지 않는다 (URL·영상 링크) | |
| 벡터 | 글을 숫자로 바꾼 값. 비슷한 내용을 찾을 때 쓰며 Qdrant에 저장 | |
| 재발견 메모 | 기록에 날짜별로 덧붙이는 새로운 의미나 쓰임 (UI 미정) | |
| 연결 | 두 기록을 잇는 선. AI가 추천하고 사용자가 수락 (P1, 보류) | 모아보기 (이어보기·별자리라고 쓰지 않음) |
| 블랙홀 | 정한 기간이 지난 기록을 모아 다시 보거나 정리하는 곳 (P1, v2에서 숨김) | 블랙홀 |
| 처리 상태 | 저장·자동 가공(글자 추출 + 검색 색인) 상태: uploading, queued, processing, done, failed, deleting | 형성 중인 별 등 |
| 연관 기록 | 기록 상세에서 보여 주는 비슷한 기록. 유사도 0.8 이상 상위 3개. 연결(별자리)과는 다르며 버튼 없이 링크로만 보여 준다 | |
| 수집 경로 | 기록이 들어온 곳: desktop, web, mcp | |
| 물어보기 | 내 기록 안에서만 답하는 AI 챗봇 | |
| MCP | ChatGPT, Claude 등 평소 쓰는 AI와 연결하는 방식 | |
| List / Space | 홈의 보기 방식 두 가지: 문서 목록 / 우주 공간. 1D·3D라고 쓰지 않는다 | List, Space |
| 목록 창 | List에서 좌상단에 떠 있는 창. 모바일에서는 사이드바 | |
| 그룹 창 | Space에서 행성을 누르면 오른쪽에 열리는 창 | |
| 빠른 분류 | '분류 안 된 기록' 카드에서 그룹 버튼으로 바로 옮기는 기능 (화면정의서 F-08) | |
| 리마인드 | N일 전 오늘 넣은 기록을 다시 보여 주는 것 (P1, v2에서 숨김) | 리마인드 |
| 우주먼지 | 도움말 챗봇 이름. 버튼 글자는 '물어보기' | 물어보기 |
| 시안 | docs/design/의 웹 시안(spacelog-prototype.html, spacelog-login.html). 화면 명세는 이 시안과 화면정의서(docs/screen-definition/) 기준. 이전 버전은 git 이력에서 확인 | |
