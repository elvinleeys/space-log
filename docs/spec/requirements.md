# 요구사항

PRD에는 요구사항 번호가 없어 PRD 기능과 팀 결정을 기준으로 R1~R10을 매겼다.

| 번호 | 요구사항 | 우선순위 | 근거 |
| --- | --- | --- | --- |
| R1 | 구글 계정으로 로그인하고, 데스크톱 앱과 웹에서 같은 기록을 쓴다 | P0 | PRD 6-1 |
| R2 | 여러 형식의 정보를 분류 부담 없이 한 번에 저장한다 | P0 | PRD 4-1, 5-1 |
| R3 | 저장 창에서 'AI 추천' 버튼을 누르면 파일을 먼저 올려 가공 서버가 파일 내용과 메모로 기존 그룹 중 하나를 추천한다. 분류하지 않고 저장한 기록은 가공 후 AI가 그룹을 추천한다. 추천은 선택만 바꾸고 사용자가 확정한다 | P0 | PRD 4-1, 6-3, 팀 결정 (PRD 원칙 1의 '미리 선택'과 다름, PRD 작성자 확인 필요) |
| R4 | 저장한 내용은 자동으로 글자를 뽑아 검색할 수 있게 색인하고, 사용자가 'AI 분석하기'나 챗봇으로 요청하면 요약(AI 정리글)한다 | P0 | PRD 4-5, 디자인 싱크 (PRD의 '저장하면 요약'과 다름, PRD 작성자 확인 필요) |
| R5 | 목록, 검색, 기간, 그룹으로 기록을 다시 찾는다 | P0 | PRD 6-3, 시안 |
| R6 | AI 챗봇에 물어 기록을 찾는다. 내 기록 안에서만 답하고 근거 기록을 보여 준다. 사용자가 제외한 그룹은 챗봇과 MCP 찾기에서 검색하지 않는다 | P0 | PRD 4-2, 4-3, 5-2, 팀 결정 |
| R7 | 평소 쓰는 AI(MCP)에서 기록을 찾고 저장한다 | P0 | PRD 5-2 |
| R8 | 기록에 재발견 메모를 날짜별로 덧붙인다 | P1 | PRD 5-3 |
| R9 | AI가 비슷한 기록을 연결 후보로 추천하고, 사용자가 수락·거절해 별자리를 만든다 | P1 | PRD 5-3 |
| R10 | 정한 기간이 지난 기록을 블랙홀에서 다시 보거나 정리한다 | P1 | PRD 5-4 |
