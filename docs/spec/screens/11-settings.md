# 설정 · 계정 (웹)
담당: 웹 · 우선순위: P0 (리마인드는 P1) · 요구사항: R7, R10 · 기능: F10, F12
화면정의서: S-06, F-24, F-26 (docs/screen-definition/screen-definition-v1.md)

목록 창의 설정 버튼을 누르면 목록 창 안에 계정 영역이 펼쳐진다 (별도 창 아님). 챗봇이 읽지 않을 그룹은 챗봇 설정 탭에 있다 (screens/08-chat.md).

## 구성 요소
- 계정 영역 맨 위: 닉네임(연필 아이콘으로 수정, 2~12자, ✓ 저장 · ✕ 취소)과 로그인 이메일(캡션, 회색). 이메일이 길면 `…`로 자르고, 잘렸을 때만 `⌄`가 생겨 누르면 펼친다
- 구분선 아래 Google 줄: 오른쪽에 '연동하기' 또는 '연동 해제' 하나만 보인다 ('연동됨' 표시 없음). 이메일 계정으로 로그인했을 때만 보이고, Google 계정으로 로그인했으면 Google 줄이 없다 (2026-11-28 결정. 시안과 다름: 시안 v3는 Google 로그인 계정에도 Google 줄을 보여 줌)
- 목록 창의 사용자 이름, 로그아웃 (로그인 전에는 같은 자리에 로그인)
- (보류) MCP 연결: ChatGPT, Claude 등과 연결하고 연결 상태 확인. 화면정의서 v2에 없음
- (보류) 리마인드 기간과 알림 (P1). 화면정의서 4절에서 리마인드 카드는 숨김
- (보류) 프로필 사진. 표시 이름(닉네임) 변경은 위 계정 영역에서 한다 (시안 v3)
- 테마 전환은 없다. 다크 모드만 쓴다 (화면정의서 4절)

## 동작
- 설정 버튼을 누른다. 목록 창 안에 계정 영역이 펼쳐진다
- Google 연동은 이메일(자체 로그인) 계정에 Google 계정을 연결하는 기능이다. 연결하면 Google로도 같은 계정에 로그인할 수 있다 (Supabase 계정 연결)
- 미연동이면 '연동하기', 연동되면 '연동 해제'. 토스트 'Google 계정을 연동했어요', 'Google 연동을 해제했어요'
- 로그인 전이면 '먼저 로그인해 주세요'
- 연동에 실패하면 미연동 상태를 유지한다 ('Google 연동에 실패했어요' 제안)
- 로그아웃은 확인을 묻지 않는다 (제안). 로그아웃해도 기기에 남긴 보기 방식은 유지하고, 기록과 챗봇 대화 목록은 보이지 않게 한다. 로그아웃하면 로그인 페이지로 가서 '로그아웃했어요. 다시 로그인하면 기록을 볼 수 있어요.'를 보여 준다. 로그아웃 상태로 홈에 들어오면 로그인 페이지로 보낸다
- (보류) 평소 쓰는 AI를 연결한다. 그 AI 안에서 내 기록을 찾고 저장한다. MCP로 저장한 기록은 '분류 안 된 기록'에 들어간다. 가공이 끝나면 AI가 추천 그룹을 남기고, 자동으로 옮기지는 않는다 (F3)
- (보류) 리마인드 기간을 정한다
- 닉네임을 바꾼다. 연필 아이콘 → 입력칸 → ✓ 저장 · ✕ 취소. 2~12자가 아니면 저장하지 않는다. 사이드바에 바로 반영되고, 이후 구글 정보가 바뀌어도 덮어쓰지 않는다

## 확인 필요
- MCP 연결 위치와 사용자 인증 방식 (화면정의서 v2에 설정 화면이 없음)
- 노션 연동 대신 md 파일 가져오기 (PRD 7)를 둘 위치
