# 설정 (웹)
담당: 웹 · 우선순위: P0 (리마인드는 P1) · 요구사항: R7, R10 · 기능: F10, F12

평소 쓰는 AI 연결, 리마인드 기간, 화면 표시를 관리한다.

## 구성 요소
- MCP 연결: ChatGPT, Claude 등과 연결하고 연결 상태 확인
- 리마인드 기간과 알림 (P1)
- 테마 전환 (시안 A), 캐릭터 (시안 B)
- 계정 정보, 로그아웃

## 동작
- 평소 쓰는 AI를 연결한다. 그 AI 안에서 내 기록을 찾고 저장한다. MCP로 저장한 기록도 AI 추천 그룹 또는 '분류 안 된 기록'에 들어간다
- 리마인드 기간을 정한다

## 확인 필요
- MCP 연결 시 사용자 인증 방식
- 노션 연동 대신 md 파일 가져오기 (PRD 7)를 둘 위치
- 시안 B 캐릭터 기능 범위
