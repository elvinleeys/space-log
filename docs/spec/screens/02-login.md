# 로그인 (데스크톱, 웹)
담당: 웹(로그인 페이지, 콜백 이동) + 데스크톱(임시 서버, 토큰 교환) · 우선순위: P0 · 요구사항: R1 · 기능: F1

이메일 계정이나 Google 계정으로 들어와 데스크톱 앱과 웹에서 같은 기록을 쓴다.

## 구성 요소
- 첫 화면: 'Google로 계속하기', '이메일로 로그인', '처음이신가요? 회원가입', 아래 회색 약관 문구 '계속하면 이용약관과 개인정보 처리방침에 동의하는 것으로 봐요.'
- 이메일 로그인: 이메일, 비밀번호(눈 아이콘으로 보기·숨기기), '비밀번호를 잊었어요', '로그인'(누르면 '로그인하는 중'), '계정이 없나요? 회원가입 | 다른 방법으로 로그인'
- 메일 보냄 화면: '메일함을 확인해 주세요', '(이메일)으로 비밀번호 재설정 링크를 보냈어요.', '10분 안에 링크를 눌러 새 비밀번호를 정해 주세요.', '메일이 안 보이면 스팸함도 확인해 주세요.', '메일 다시 보내기 (n초 후)', '로그인으로 돌아가기'
- 회원가입: 닉네임('우주에서 불릴 이름이에요 · 2~12자'), 이메일, 비밀번호(조건 '8자 이상' · '영문과 숫자 함께' 체크 표시), 비밀번호 확인, '이용약관과 개인정보 처리방침에 동의해요 (필수)', '가입하기'(누르면 '가입하는 중'), '이미 계정이 있나요? 로그인 | Google로 가입하기'
- 칸 오류는 칸 아래 붉은 한 줄. 화면 단위 안내(로그인 실패, 로그인 만료, 로그아웃)는 맨 아래 붉은 박스에 두 줄
- 로그아웃 버튼: 목록 창 (화면정의서 F-26)

## 동작
- 이메일과 비밀번호로 가입하고 로그인한다. 인증 메일은 보내지 않고 가입하면 바로 로그인된다 (Supabase Confirm email 끔, 2026-11-28)
- Google 계정으로 바로 가입하거나 로그인할 수도 있다 (Supabase Google 로그인)
- 처음 로그인하면 사용자와 기본 그룹 '분류 안 된 기록'을 만든다. 표시 이름은 이메일 가입이면 가입 때 쓴 닉네임, Google 가입이면 구글 이름
- 'Google로 계속하기'를 누르면 'Google 창에서 로그인을 마쳐 주세요' + 점 3개를 보여 준다
- 칸 오류 문구
  - 이메일 형식: '이메일 주소를 다시 확인해 주세요. 예: name@example.com'
  - 이메일·비밀번호 불일치: '이메일 또는 비밀번호가 맞지 않아요. 다시 확인해 주세요.'
  - 닉네임: '닉네임은 2~12자로 정해 주세요.'
  - 비밀번호 확인: '비밀번호를 한 번 더 입력해 주세요.', '비밀번호가 서로 달라요.'
  - 약관: '약관에 동의해야 가입할 수 있어요.'
  - 이미 가입된 이메일: '이미 가입된 이메일이에요.' + '로그인하기'
- 비밀번호 찾기: '비밀번호를 잊었어요'를 누른다. 이메일 칸이 비었으면 '비밀번호를 재설정할 이메일을 먼저 입력해 주세요.' 이메일이 있으면 재설정 메일을 보내고 메일 보냄 화면으로 간다. 링크는 10분 동안 쓸 수 있다. '메일 다시 보내기'는 보낸 뒤 30초 동안 '메일 다시 보내기 (n초 후)'로 막힌다 (시안 v3). 만료된 링크로 들어오면 '비밀번호 재설정 링크가 만료됐어요. 비밀번호를 잊었어요를 눌러 새 링크를 받아 주세요.'
- 화면 단위 안내
  - 로그인 실패: '로그인하지 못했어요. 다시 시도해 주세요.'
  - 로그인 만료: '오래 쓰지 않아 로그아웃됐어요. 다시 로그인하면 보던 화면으로 돌아가요.'
  - 로그아웃: '로그아웃했어요. 다시 로그인하면 기록을 볼 수 있어요.'
- 로그아웃하면 로그인 페이지로 간다. 로그아웃 상태로 홈에 들어오면 로그인 페이지로 보낸다
- 이메일 계정은 설정의 'Google 연동'으로 Google 계정을 연결할 수 있다. 연결하면 Google로도 같은 계정에 로그인한다 (screens/11-settings.md). Google로 로그인한 계정에는 'Google 연동'이 보이지 않는다
- 같은 이메일의 이메일 계정과 Google 계정은 Supabase 기본 동작대로 한 계정으로 묶는다
- 데스크톱 앱에서 로그인을 누른다. 앱이 127.0.0.1의 임의 포트에 임시 서버를 열고 브라우저로 웹 로그인 페이지를 연다 (이메일·Google 모두 웹에서 로그인)
- 웹에서 로그인에 성공하면 http://127.0.0.1:포트/callback 주소로 일회용 코드를 보낸다
- 앱이 코드와 PKCE 검증값(코드를 가로채도 쓰지 못하게 하는 확인값)을 서버에 보내 토큰으로 바꾸고, 임시 서버를 닫는다

## 확인 필요
- 첫 로그인 후 스페이스 생성·안내 화면 유무
- 포트와 PKCE 값을 웹 로그인 페이지에 넘기는 방식, 토큰 교환을 맡는 서버, 토큰 보관 위치
- 브라우저 로그인을 끝내지 않고 닫았을 때 임시 서버 처리
- 새 비밀번호를 정하는 화면 (시안 v3에 없음)
- 로그인 만료 뒤 '보던 화면'으로 돌려보내는 방식 (돌아갈 주소 보관)
