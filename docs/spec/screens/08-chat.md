# 물어보기 (웹)
담당: 웹 · 우선순위: P0 · 요구사항: R3, R4, R6 · 기능: F3, F4, F9

AI 챗봇에 물어 그룹에 넣지 않은 기록까지 찾는다. 답은 내 기록 안에서만 하고 근거 기록을 함께 보여 준다.
기록 분석을 요청하고, 분류 안 된 기록의 그룹 추천(AI 추천)도 받을 수 있다. 화면은 임시 시안(2026-11-28 디자인 싱크) 기준이다.

## 구성 요소
- 물어보기 버튼 (메인 우주 하단)
- 상단: 뒤로, 대화 제목(예: '예전 기록을 다시 보려면'), 닫기
- 인사와 안내: 캐릭터 '우주먼지' 인사 (시안 A), "답 아래에 근거가 된 별이 보여요" 안내 (시안 B)
- 추천 질문 버튼: 사용법 질문 (시안 A), 기록 질문 예시 (시안 B)
- **자주 묻는 질문(FAQ)**: 분석 요청을 유도하는 질문을 넣을 수 있다 (예: '이번 주 기록 분석해줘') [확인 필요: FAQ 목록과 문구]
- **AI 추천 버튼**: '분류 안 된 기록'의 그룹 추천 (F3) [확인 필요: 결과를 챗봇 안에서 보여 주고 바로 수락할지, 행성 패널로 보낼지]
- 질문 입력창, 묻기 버튼
- 답변과 근거 기록 목록
- 분석 답변 아래 버튼: **크게 보기**(답변 전체를 넓게 보기), **기록으로 저장**
- 새 대화 버튼 (시안 B), 하단 탭 홈·대화·설정 (시안 A)

## 동작
- 질문을 입력한다. 내 기록에서 찾은 내용으로 답하고, 근거 기록의 그룹과 제목을 보여 준다
- 근거 기록을 고른다. 기록 상세를 연다
- 관련 기록이 없으면 내 기록에서 찾지 못했다고 답하고, 외부 지식으로 답하지 않는다
- **묶음 분석**: '이번 주 기록 분석해줘'처럼 기간·그룹 단위로 요청하면 기록들을 그룹별로 정리해 답한다 (예: 넣은 기록 수, 그룹 수, 가장 많이 넣은 그룹, 메모가 있는 기록 수, 그룹별 기록 제목과 메모 앞부분). 답변은 각 기록의 AI 분석 칸에 저장하지 않는다
- **기록 하나 분석**: '이 기록 분석해줘'처럼 기록 하나를 요청하면 기록 상세의 'AI 분석하기'와 같은 분석을 하고 그 기록의 AI 분석 칸에 저장한다. 이미 분석된 기록이면 '다시 분석'과 같은 규칙(메모가 바뀌었을 때만)을 따른다
- **기록으로 저장**: 분석 답변을 새 chat 기록으로 저장한다. 답변은 그 기록의 AI 분석 칸에 들어가 'AI 분석하기' 버튼이 없고, 근거 기록을 함께 남긴다. 그룹은 '분류 안 된 기록'
- **AI 추천**: 분류 안 된 기록마다 어울리는 그룹을 추천한다 (F3)

## 확인 필요
- 시안 A처럼 사용법 질문에도 답할지, 답한다면 기록 답변과 어떻게 구분할지
- 대화 기록 저장 여부
- 시안 A 하단 탭의 홈·설정 내용
- FAQ 목록과 문구, AI 추천 결과를 보여 주는 위치
