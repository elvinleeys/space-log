# 물어보기 (웹)
담당: 웹 · 우선순위: P0 · 요구사항: R6 · 기능: F9

AI 챗봇에 물어 그룹에 넣지 않은 기록까지 찾는다. 답은 내 기록 안에서만 하고 근거 기록을 함께 보여 준다.

## 구성 요소
- 물어보기 버튼 (메인 우주 하단)
- 인사와 안내: 캐릭터 '우주먼지' 인사 (시안 A), "답 아래에 근거가 된 별이 보여요" 안내 (시안 B)
- 추천 질문 버튼: 사용법 질문 (시안 A), 기록 질문 예시 (시안 B)
- 자주 묻는 질문 (시안 A)
- 질문 입력창, 묻기 버튼
- 답변과 근거 기록 목록
- 새 대화 버튼 (시안 B), 하단 탭 홈·대화·설정 (시안 A)

## 동작
- 질문을 입력한다. 내 기록에서 찾은 내용으로 답하고, 근거 기록의 그룹과 제목을 보여 준다
- 근거 기록을 고른다. 기록 상세를 연다
- 관련 기록이 없으면 내 기록에서 찾지 못했다고 답하고, 외부 지식으로 답하지 않는다

## 확인 필요
- 시안 A처럼 사용법 질문에도 답할지, 답한다면 기록 답변과 어떻게 구분할지
- 대화 기록 저장 여부
- 시안 A 하단 탭의 홈·설정 내용
