# 물어보기 (웹)
담당: 웹 · 우선순위: P0 · 요구사항: R3, R4, R6 · 기능: F3, F4, F9
화면정의서: S-05, S-05a, F-18 ~ F-23 (docs/screen-definition/screen-definition-v1.md)

AI 챗봇 '우주먼지'에 물어 그룹에 넣지 않은 기록까지 찾는다. 답은 내 기록 안에서만 하고 근거 기록을 함께 보여 준다.
기록 분석을 요청하고, 분류 안 된 기록의 그룹 추천(AI 추천)도 받을 수 있다.

## 구성 요소
- 물어보기 버튼: '+ 기록 넣기' 오른쪽에 붙어 한 세트로 가운데 정렬. 끌어서 옮길 수 있고 위치를 기억한다. 위에 말풍선 '기록을 찾아봐요' (× 로 닫으면 다시 뜨지 않음)
- 챗봇 창: 폭 440px(1100px 미만 400px), 아래에서 84px. 하단 버튼과 겹치지 않는다
- 아래 탭: FAQ, 대화, 설정 (첫 탭 이름은 'FAQ')
- 대화 탭: 대화 목록(제목 · 시간 · 지우기), 새 대화
- 새 대화: 첫 인사 '안녕하세요, 우주먼지예요. 무엇을 찾고 있나요?', 추천 질문 칩, 입력창, '자주 묻는 질문 →'
- 입력창: 한 줄 52px에서 최대 4줄(112px)까지 늘어남. 보내기 버튼
- 답 말풍선, 출처 기록 카드, '기록으로 저장'과 같은 줄의 바로가기 버튼, 이어지는 추천 질문. 긴 답은 '새 창으로 보기'
- **AI 추천**: 따로 버튼을 두지 않고 FAQ 질문 '분류 안 된 기록 정리해줘'로 넣는다 (F3)

## 동작
- 물어보기 버튼을 누르면 챗봇 창을 연다. 다시 누르면 닫힌다
- 대화가 있었으면 대화 목록부터, 없으면 바로 새 대화를 연다
- 창을 닫으면 대화를 목록에 저장한다. 목록에서 대화를 지울 수 있다
- 추천 질문 칩은 처음 5개, 대화 뒤 4개. 이미 물은 질문은 빠진다. 맨 앞은 '이번 주 기록 정리해줘'
- 빈 입력은 보내지 않는다. 보내기 버튼은 비어 있으면 흐린 화살표, 글이 있으면 옅은 회색 원 + 흰 화살표
- 질문을 입력한다. 내 기록에서 찾은 내용으로 답하고 출처 기록 카드를 보여 준다. 답 형식은 파일 내용과 메모를 바탕으로 한 핵심 1줄 + 요약 3개 (기록 상세 AI 분석과 같음). 묶음 분석은 보고서로 답하고 새 창에서 본다 (아래 '묶음 분석')
- 출처 카드를 누르면 그 기록 상세로 간다
- 관련 기록이 없으면 내 기록에서 찾지 못했다고 답하고, 외부 지식으로 답하지 않는다 (프로토타입 문구 '거기까지는 아직 떠다녀 보지 못했어요.')
- 기록을 찾는 질문에 맞는 기록이 없으면 '찾는 기록을 찾지 못했어요. 그룹별 AI 기록 수집 기능이 꺼져 있으면 기록이 수집되지 않을 수 있으니 확인해 주세요.'라고 답한다. 'AI 활용 꺼짐' 그룹이 있으면 '지금 꺼져 있는 그룹: ‘그룹 이름’, …' 줄과 '챗봇 설정 바로가기' 버튼을 붙인다 (시안 v3). 그 그룹에 맞는 기록이 실제로 있는지는 판단하지 않는다
- 답이 화면의 버튼을 가리키면 우주먼지가 그 버튼 옆으로 날아가 안내한다 (챗봇 창에 가려지면 날아가지 않음)
- **기록으로 저장**: 답을 새 chat 기록으로 '분류 안 된 기록'에 저장한다. 버튼이 '기록으로 저장됨'으로 바뀌고, 다시 누르면 저장을 취소한다('저장을 취소했어요'). 저장한 기록은 답이 AI 분석 칸에 들어가 'AI 분석하기' 버튼이 없고, 근거 기록을 함께 남긴다
- **바로가기 버튼**: 답이 화면 기능을 가리키면 '기록으로 저장'과 같은 줄에 바로가기 버튼을 붙인다: 기록 넣기 열기 · 검색창으로 가기 · 이번 주 기록 보기 · 전체 기간으로 보기 · 챗봇 설정 바로가기
- **긴 답 새 창으로 보기** (화면정의서 F-21): 긴 답은 말풍선에서 196px까지만 보이고 아래가 흐려지며 '새 창으로 보기'가 생긴다 ('크게 보기'를 대체). 누르면 챗봇 창과 같은 크기의 **요약 창**(핵심 1줄 + 요약 3개)이 열린다. '전체 보고서 보기'를 누르면 넓은 창에 전체 보고서(아래 '복사' · '기록으로 저장')가 열리고, '‹ 요약으로'로 요약 창에 돌아간다. 넓은 PC는 챗봇 창 왼쪽에 최대 640px 패널, 좁은 PC는 챗봇 위 가운데 최대 720px, 760px 미만은 전체 화면 페이지에 '← 대화로'. 닫기는 '새 창 닫기'. 복사 실패는 '복사하지 못했어요'
- **자주 묻는 질문** (화면정의서 F-22): FAQ 탭이나 새 대화의 '자주 묻는 질문 →'을 누르면 창이 넓어지며 질문 목록이 나온다. 처음에는 모두 닫혀 있고, 질문을 누르면 답이 펼쳐진다. '대화로 돌아가기'. 질문: 기록은 어떻게 넣어요 · 이번 주 기록 알려주세요 · AI 분석이 뭐예요 · 그룹을 지우고 싶어요 · Space로 볼 수 있나요 · 기록이 안 보여요 · 그룹 색을 바꾸고 싶어요 · 기록을 다른 그룹으로 옮기려면 · 기록을 검색할 수 있나요 · 분류 안 된 기록 정리해줘. 맨 아래에 '모아보기가 뭐예요' · '예전 기록을 다시 보려면'을 '(준비중)'과 함께 어두운 회색으로 둔다. '리마인드가 뭐예요'는 뺀다 (시안 v3. 시안에는 '분류 안 된 기록 정리해줘'가 없지만 2026-11-28 결정대로 남긴다). 분석 요청을 유도하는 질문을 넣을 수 있다 (예: '이번 주 기록 분석해줘')
- **챗봇 설정** (화면정의서 F-23): 설정 탭 맨 위 '챗봇이 읽지 않을 그룹' 체크 목록 ('챗봇이 읽은 기록' 줄은 없다, 시안 v3). 체크한 그룹은 'AI 활용 꺼짐'이 되어 그 기록을 답과 출처에 쓰지 않고, AI 분석('AI 분석하기'·'다시 분석')과 기록 상세 'AI 추천'도 막는다. 자동 가공(글자 추출·원문 조각 벡터)은 그대로다. 챗봇 켜기/끄기는 없다 (항상 켜짐)
- **묶음 분석**: '이번 주 기록 분석해줘'처럼 기간·그룹 단위로 요청하면 보고서로 답하고, 새 창(요약 창 → 전체 보고서)에서 본다. 보고서 순서: 소개 한 줄('이번 주에 넣은 기록을 그룹별로 정리했어요. 기록 제목 옆은 남겨 둔 메모의 앞부분이에요.') → 한눈에 보기(기록 n개 · 그룹 n곳, 가장 많이 넣은 그룹, 메모를 남긴 기록 수 · 메모가 없는 기록 수) → 그룹별 목록('그룹 · n개' 아래 '제목 — 메모 앞부분') → 자주 나온 낱말('낱말 · n번') → 다음에 해 볼 것. 기간 안 기록이 없으면 '이번 주에 넣은 기록이 아직 없어요.' 답변은 각 기록의 AI 분석 칸에 저장하지 않는다
- **기록 하나 분석**: '이 기록 분석해줘'처럼 기록 하나를 요청하면 기록 상세의 'AI 분석하기'와 같은 분석을 하고 그 기록의 AI 분석 칸에 저장한다. 이미 분석된 기록이면 '다시 분석'과 같은 규칙(메모에 새로 쓴 글자 10자 이상)을 따른다. 'AI 활용 꺼짐' 그룹의 기록은 분석하지 않는다
- **AI 추천**: FAQ의 '분류 안 된 기록 정리해줘'를 누르거나 같은 뜻으로 물으면, 분류 안 된 기록마다 어울리는 기존 그룹을 골라 대화창 답에 '기록 → 추천 그룹' 목록으로 보여 준다 (F3). 자동으로 옮기지 않고, 수락은 List '분류 안 된 기록'의 빠른 분류 카드에서 한다
- 챗봇 창 안의 요소를 끌어다 놓는 것은 기록으로 받지 않는다
- 760px 미만은 전체 화면 페이지. 모바일 사이드바가 열린 동안 물어보기 버튼을 숨긴다

## 확인 필요
- 사용법 질문(화면 안내)에 답할지, 답한다면 기록 답변과 어떻게 구분할지
- '긴 답' 기준 (글 길이, 예: 8줄 이상)
- 요약 창의 핵심 1줄 + 요약 3개를 보고서와 함께 한 번에 만들지
- 자주 나온 낱말을 세는 방식 (시안은 예시 숫자)
- 대화 목록을 계정 데이터로 저장하는 방식 (프로토타입은 브라우저 저장)
