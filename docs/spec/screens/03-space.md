# 홈 · List / Space (웹)
담당: 웹 · 우선순위: P0 · 요구사항: R3, R5, R9, R10 · 기능: F3, F5, F6
화면정의서: S-01, S-02, F-01 ~ F-04, F-09, F-25 (docs/screen-definition/screen-definition-v1.md)

첫 화면. 보기 방식은 List(문서 목록)와 Space(우주 공간) 두 가지이고, 목록 창에서 바꾼다. 다크 모드만 쓴다.

## 구성 요소
- 목록 창 (좌상단에 떠 있음): 로고·접기 버튼, 사용자 이름·로그아웃·설정, 보기 전환 [List | Space], 그룹 바로가기
- 그룹 바로가기: + 새 그룹, 전체 보기 (List만), 그룹마다 색상 점·이름·기록 수, '분류 안 된 기록' (맨 아래). 이 영역만 스크롤
- Space 목록 창 맨 아래: '처음이라면 이렇게 날아요' 접이식 이동 안내
- 검색창: 위에서 24px, 높이 44px
- 기간 바 (우상단): ‹ 직접 지정 ›, 전체, 오늘, 이번 주, 이번 달
- List 본문: 기록 목록 (screens/06-record-list.md)
- Space 본문: 그룹 행성과 이름표(그룹 이름 · 기록 n), '분류 안 된 기록' 성운(조각 n), 우주인 캐릭터
- 하단 버튼: + 기록 넣기, 물어보기

## 동작
- 첫 진입은 List로 연다. 마지막으로 고른 보기를 기억해 다음 진입 때 그대로 연다
- 보기를 바꿔도 기간, 선택한 그룹, 체크한 기록은 유지한다
- Space를 불러오지 못하면 토스트 'Space 보기를 불러오지 못했어요'를 띄우고 List를 유지한다
- 목록 창을 접으면 아이콘만 남은 세로 줄이 되고 50%로 흐려진다. 마우스를 올리면 100%
- 그룹을 누른다. List는 가운데 목록이 그 그룹으로 걸러지고, Space는 행성으로 날아가 그룹 창(screens/04-planet-panel.md)을 연다
- 기간을 바꾼다. 목록·우주와 그룹별 기록 수가 그 기간 기준으로 바뀐다. 기준은 기록을 넣은 시각이다
- 첫 진입 기간은 '오늘'. 오늘 기록이 0개면 '이번 주'로 열고 '오늘은 아직 기록이 없어서 이번 주를 보여드려요'를 보여 준다
- '전체'에서 ‹ ›를 누르면 토스트 '전체 기간에서는 앞뒤로 넘길 수 없어요'
- 검색어를 입력하면 바로 결과로 바뀐다. 지금 기간 안에서 제목·출처·메모로 찾는다. List는 가운데 목록이 결과로 바뀌고, Space는 검색창 아래 결과 목록이 펼쳐진다. 목록 창 숫자는 'n개 일치'로 바뀐다
- 결과가 없으면 '조건에 맞는 기록이 없어요. 위쪽 기간을 넓혀 보세요.'
- Space 이동: 방향키, Space 상승, Shift 하강, 드래그 시점, 휠 앞뒤, E 착륙. 행성을 누르면 날아가 착륙(약 800ms)하고 그룹 창을 연다
- Space에서 빈 공간을 누르면 열린 창을 닫는다 (드래그·휠은 닫지 않음). 입력칸에 포커스가 있으면 이동 키를 받지 않는다
- Esc는 한 단계씩 닫는다 (상세 → 그룹 창 → 기본 화면)
- 파일을 화면에 끌어다 놓거나 붙여넣는다. 기록 넣기 창을 연다
- 새 그룹을 누른다. 이름, 색상 7가지, 모양 5가지를 정해 만든다 (screens/04-planet-panel.md)
- 처리 중인 기록은 형성 중인 별처럼 구분해 보인다 [확인 필요: 화면정의서에 처리 중 기록 표시가 없음. List·Space에서 어떻게 보일지]
- 모바일(1100px 미만)은 상단바(목록 열기 · 홈 · 시계(기간) · 검색)와 왼쪽 사이드바(목록 창)로 바뀐다. 760px 미만은 창이 화면 가득. 자세한 규칙은 화면정의서 F-25
- 별자리(모아보기)와 블랙홀은 보류·숨김 (화면정의서 4절)

## 확인 필요
- 직접 지정 기간: 화면정의서 0-3은 '고른 날짜 하루 (‹ ›로 하루씩 이동)', F-03은 '시작일 – 종료일 날짜 칸'. 어느 쪽인지
- 검색 대상에 파일 본문(PDF 글자 등)을 넣을지
- Space 검색 결과 0개일 때 안내
- 3D 라이브러리, 휴대폰에서 Space 이동 방식 (화면정의서는 모바일에서 이동 키 안내를 숨긴다고만 함)
