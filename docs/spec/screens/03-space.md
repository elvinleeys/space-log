# 메인 우주 (웹)
담당: 웹 · 우선순위: P0 · 요구사항: R3, R5, R9, R10 · 기능: F3, F5, F6

그룹은 행성, 기록은 별로 보이는 첫 화면에서 기록을 둘러보고 각 기능으로 들어간다.

## 구성 요소
- 사이드바: 사용자 이름(처음엔 구글 이름, 설정에서 변경 가능), 프로필 사진, 로그아웃, 설정, 테마 전환 (시안 A), 캐릭터 버튼 (시안 B), 접기 버튼
- 그룹 바로가기: 그룹마다 색상 점, 이름, 기록 수. 새 그룹 버튼, 전체 보기 (시안 A), '분류 안 된 기록'
- 기간 요약: 이 기간 기록 수와 행성 수 (시안 B)
- 검색창: 제목, 출처, 메모로 찾기
- 기간 필터: 오늘, 이번 주, 이번 달, 전체, 직접 지정
- 3D 우주: 그룹 행성과 이름·기록 수 라벨, '분류 안 된 기록' 성운, 우주 비행사 캐릭터
- 하단 버튼: 기록 넣기, 물어보기
- 조작 안내: 키보드 비행, 시점 드래그, Enter 착륙 (시안 B)

## 동작
- 그룹 바로가기나 행성을 누른다. 행성으로 이동하고 행성 상세 패널을 연다
- 기간을 바꾼다. 우주와 그룹별 기록 수가 그 기간 기준으로 바뀐다
- 검색어를 입력한다. 조건에 맞는 기록을 확인한다
- 파일을 우주에 끌어다 놓거나 붙여넣는다. 기록 넣기 창을 연다
- 새 그룹을 누른다. AI가 그룹 이름을 추천하고, 사용자가 고쳐서 만든다
- 처리 중인 기록은 형성 중인 별처럼 구분해 보인다
- (P1) 연결된 기록이 별자리로, 기간이 지난 기록이 블랙홀로 보인다

## 확인 필요
- 검색 결과를 기록 목록 화면에 보여 줄지, 우주 위에 보여 줄지
- 3D 라이브러리, 휴대폰에서 우주 이동 방식 (시안 B 키보드 비행 대체)
