# 블랙홀 (웹, P1)
담당: 웹 · 우선순위: P1 · 요구사항: R8, R10 · 기능: F12

정한 기간이 지난 기록을 모아 다시 보거나 정리한다.

**보류·숨김**: 화면정의서 v2(4절)에서 블랙홀은 Space에서 숨기고, 리마인드 카드('N일 전 오늘의 기록')는 목록 창에서 숨긴다. 구현 범위에서 뺀다.
화면정의서 0-1의 리마인드는 'N일 전 오늘 넣은 기록을 다시 보여 주는 것'('재발견 혜성'은 쓰지 않음). 기간이 지난 기록을 모으는 블랙홀과는 뜻이 다르다.

## 구성 요소
- 우주의 블랙홀
- 기간이 지난 기록 목록
- 기록별 지우기, 그대로 두기 버튼

## 동작
- 정한 기간이 지난 기록이 생기면 우주에 블랙홀이 생긴다
- 블랙홀을 고른다. 기간이 지난 기록 목록을 확인한다
- 기록마다 지우거나 그대로 둔다. 지우기는 확인 창 후 기록 삭제 절차(docs/database.md)를 따른다
- 기록을 고른다. 기록 상세가 열린다

## 확인 필요
- 기간 기준 (저장한 날, 마지막으로 본 날)
- 그대로 둔 기록이 다시 블랙홀에 들어오는지, 알림 채널
- 화면정의서는 블랙홀을 '그룹 보관'으로 적음. 이 문서의 '기간이 지난 기록 모음'과 같은 기능인지
- 리마인드(N일 전 오늘 넣은 기록)와 블랙홀을 한 기능(F12)으로 둘지 나눌지
