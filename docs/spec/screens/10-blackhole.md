# 블랙홀 (웹, P1)
담당: 웹 · 우선순위: P1 · 요구사항: R8, R10 · 기능: F12

정한 기간이 지난 기록을 모아 다시 보거나 정리한다.

## 구성 요소
- 우주의 블랙홀
- 기간이 지난 기록 목록
- 기록별 지우기, 그대로 두기 버튼

## 동작
- 정한 기간이 지난 기록이 생기면 우주에 블랙홀이 생긴다
- 블랙홀을 고른다. 기간이 지난 기록 목록을 확인한다
- 기록마다 지우거나 그대로 둔다. 지우기는 확인 창 후 기록 삭제 절차(docs/database.md)를 따른다
- 기록을 고른다. 기록 상세가 열린다

## 확인 필요
- 기간 기준 (저장한 날, 마지막으로 본 날)
- 그대로 둔 기록이 다시 블랙홀에 들어오는지, 알림 채널
