# 기록 목록 · List (웹)
담당: 웹 · 우선순위: P0 · 요구사항: R5 · 기능: F6, F7
화면정의서: F-06, F-07, F-08 (docs/screen-definition/screen-definition-v1.md)

List 보기의 가운데 목록. 기록을 표로 펼쳐 놓고 그룹·기간·검색으로 거르고, 체크해서 한꺼번에 옮기거나 지운다. Space에서는 그룹 창 목록(screens/04-planet-panel.md)이 이 역할을 한다.

## 구성 요소
- 제목 줄: '기록 n개' (그룹을 고르면 '기록 n개 · 그룹 이름', 검색 중이면 ''검색어' 검색 결과 n개')
- 보기 전환 [전체 보기 | 그룹별 보기]. 그룹별 보기는 그룹 머리줄(색 점 · 이름 · 개수)로 묶는다
- 그룹 이동, 삭제 버튼
- 기록 표: 체크, 제목·종류, 그룹(색 점 + 이름), 넣은 날. 머리줄에 전체 선택 칸
- '분류 안 된 기록'을 골랐을 때만 목록 위 기록 카드: 제목, 빠른 분류 ⌄, 상세보기, 맨 끝 + 칸
- 검색창과 기간 바는 홈 공통 (screens/03-space.md)

## 동작
- 그룹, 기간, 검색어로 기록을 거른다. 조건에 맞는 기록을 확인한다
- 기록을 고른다. 같은 자리에서 기록 상세로 바뀐다 (새 창 아님)
- 정렬은 최근 넣은 순 하나. 기간이 '오늘'이면 목록 안 날짜 줄을 숨긴다
- 넣은 날 표기: 오늘, 어제, n일 전(2~6일), 11월 20일(7일 전부터)
- 페이지 전체가 스크롤된다. 그룹을 바꿔도 제목과 목록 위치가 위아래로 움직이지 않는다
- 기간 안 기록이 0개면 '끌어다 놓으면 기록이 됩니다.' / '클립보드에서 바로 붙여넣을 수도 있어요.'
- **체크와 일괄 동작**
  - 체크박스는 항상 보인다. 체크하면 목록 위 오른쪽에 n개 선택 · 그룹 이동 · 삭제 · 취소
  - 전체 선택 칸은 일부만 고르면 가로줄로 보인다
  - 그룹 이동 메뉴 맨 위에 '새 그룹으로 옮기기'. 메뉴가 넘치면 안에서 스크롤
  - 삭제는 두 번 누른다: '삭제' → 'n개 지우기'. 지우면 기록마다 기록 삭제 절차(docs/database.md)를 따른다
  - 그룹이나 보기를 바꿔도 체크는 풀리지 않는다. 기록 상세에 들어가면 체크박스와 도구 줄을 숨긴다
  - 체크 없이 그룹 이동·삭제를 누르면 버튼 아래 말풍선으로 안내한다 (2.2초)
- **빠른 분류 카드** ('분류 안 된 기록'에서만): 빠른 분류 ⌄를 펼치면 그룹 버튼들과 '+ 새 그룹 추가하기'. 그룹 버튼을 누르면 바로 옮기고 카드가 목록에서 빠진다. 분류 안 된 기록이 0개면 카드 영역이 없다. AI 추천 표시는 screens/04-planet-panel.md 참고
- 모바일은 목록 카드 안에서만 스크롤. 1줄 '기록 n개', 2줄 그룹별 토글 · 그룹 이동 · 삭제. 체크하면 카드 맨 위 고정 줄에 전체 선택 · n개 선택 · 취소

## 확인 필요
- 휴지통: 화면정의서는 삭제 버튼을 '휴지통'으로 표시하고 '지운 기록 되살리기 기간'을 미정으로 둠. docs/decisions.md(2026-11-27)는 휴지통을 두지 않는다고 정함. 어느 쪽인지
- 일부만 옮겨지거나 지워졌을 때 안내 ('n개 중 n개를 옮겼어요' 제안)
- 목록을 불러오지 못했을 때 안내 ('기록을 불러오지 못했어요 · 다시 시도' 제안)
- 한 번에 불러올 개수와 더 불러오기 방식
- 검색 대상에 파일 본문을 넣을지
- 이미지 기록의 종류 표기 (예전 시안 B에서는 '텍스트 · PNG'로 표시됨)
