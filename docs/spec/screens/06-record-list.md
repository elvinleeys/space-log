# 기록 목록 (웹)
담당: 웹 · 우선순위: P0 · 요구사항: R5 · 기능: F6, F7

기록을 표로 펼쳐 놓고 검색과 필터로 원하는 기록을 찾는다.

## 구성 요소
- 기간 요약: "오늘 별 13개를 띄웠어요"와 기록 수·그룹 수 (시안 B)
- 그룹 고르기 목록, 새 그룹 버튼
- 검색창: 제목, 내용, 메모에서 찾기
- 필터: 그룹별로 묶기, 즐겨찾기만 보기, 기간 (시안 B)
- 기록 표: 즐겨찾기 별, 제목과 형식 정보, 그룹, 메모 미리보기, 넣은 날

## 동작
- 그룹, 기간, 검색어로 기록을 거른다. 조건에 맞는 기록을 확인한다
- 기록을 고른다. 기록 상세를 연다
- 별을 눌러 즐겨찾기를 켜고 끈다

## 확인 필요
- 즐겨찾기를 MVP에 넣을지 (PRD에 없음)
- 검색 범위. 시안 A는 제목·출처·메모, 시안 B는 제목·내용·메모. '내용'에 요약본을 넣을지
- 검색 결과가 없을 때의 처리
- 이미지 기록의 형식 아이콘·표기 (시안 B에서 '텍스트 · PNG'로 표시됨)
