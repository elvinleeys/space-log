# 연결 · 별자리 (웹, P1)
담당: 웹 · 우선순위: P1 · 요구사항: R9 · 기능: F11

AI가 추천한 비슷한 기록을 수락해 기록끼리 잇고, 이어진 기록이 우주에서 별자리로 보인다.

**보류**: 화면정의서 v2(4절)에서 모아보기(이어보기) 만들기·보기는 보류, 나중에 다시 넣을 예정. 구현 범위에서 뺀다. 화면에 쓰는 이름은 '모아보기'('이어보기', '별자리'는 쓰지 않음).

## 구성 요소
- 연결 후보 목록: AI가 추천한 비슷한 기록
- 수락, 거절 버튼
- 연결된 기록 목록
- 우주의 별자리 선

## 동작
- AI가 비슷한 기록을 연결 후보로 추천한다
- 후보를 수락한다. 두 기록을 잇는 연결을 만들고 별자리 선이 생긴다
- 후보를 거절한다
- 연결을 지운다

## 확인 필요
- 연결 후보를 보여 줄 위치 (기록 상세 안, 별도 화면, 알림)
- 추천 시점 (저장 직후, 상세를 열 때, 주기적으로)
- 거절한 후보를 다시 추천할지, 사용자가 직접 연결할 수 있는지
- 화면정의서의 모아보기는 '여러 기록을 골라 한곳에 모은 것'. 이 문서의 'AI 추천 후 두 기록을 잇는 연결'과 같은 기능인지
