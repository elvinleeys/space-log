# 기록 상세 및 재발견 메모 (웹)
담당: 웹 · 우선순위: P0 (재발견 메모는 P1) · 요구사항: R4, R5, R8 · 기능: F7, F8

기록한 정보와 원래 맥락을 다시 확인한다. 시안 캡처가 없어 화면 배치는 정하지 않았다.

## 구성 요소
- 정보 내용: URL·파일·영상 링크는 AI 정리글(한 줄 요약, 핵심 포인트, 이럴 때 다시 보세요, 바로 써먹을 것, 관련 직군 노트)과 파일 미리보기, 하이라이트는 선택 문장, 메모는 본문
- 원래 맥락: 저장할 때 남긴 메모
- 원문 링크, 그룹, 형식, 넣은 날, 처리 상태 (처리 중, 완료, 실패)
- 그룹 변경 드롭다운
- 재발견 메모 [확인 필요: UI 미정. 입력 위치, 표시 방식, 이 화면에 둘지]

## 동작
- 정보 내용과 원래 맥락을 확인한다. 출처 링크가 있으면 원문을 연다 (출처 링크는 모든 기록에서 선택)
- 그룹을 바꾼다
- 재발견 메모를 남긴다 (P1). 날짜와 함께 쌓이고 이전 메모를 덮어쓰지 않는다는 것만 정해져 있고, 화면 동작은 UI를 정한 뒤 채운다
- 기록을 지운다

## 확인 필요
- 삭제 범위: Storage 파일, Qdrant 벡터, 재발견 메모, 연결을 함께 지울지
- AI 요약본을 사용자가 고칠 수 있는지
- Storage 파일을 보여 주는 방식
