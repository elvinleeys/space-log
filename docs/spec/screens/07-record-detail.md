# 기록 상세 및 재발견 메모 (웹)
담당: 웹 · 우선순위: P0 (재발견 메모는 P1) · 요구사항: R4, R5, R8 · 기능: F4, F7, F8

기록한 정보와 메모를 다시 확인하고, 필요할 때 'AI 분석하기'로 AI 정리글을 만든다. 배치는 디자인 시안(2026-11-28 디자인 싱크) 기준이다.

## 구성 요소 (위에서 아래 순서)
- 상단: 뒤로(그룹 이름), 그룹 안 기록 이동(이전·다음, `1 / 33`)
- 제목, 형식·파일 수·크기·넣은 날 (예: 이미지 · 파일 3개 · 2.6MB · 11월 27일 넣음)
- 파일 미리보기: 파일마다 썸네일, 화면 이름(`displayFileName`), 형식·크기
- 링크 추가하기 (출처 주소 source_url, 모든 기록에서 선택)
- **AI 분석 영역** (아래 '버튼과 상태')
- **메모** (original_context): 수정하면 자동 저장, '자동 저장됨' 표시. 메모·하이라이트 기록은 본문(information_content)을 메모 위에 따로 보여 준다
- 그룹: 현재 그룹과 옮기기 ("스페이스에서도 반영돼요"). '분류 안 된 기록'에 있을 때만 옆에 'AI 추천' (아래 '그룹과 AI 추천')
- 삭제 버튼, 삭제 확인 창
- 재발견 메모 [확인 필요: UI 미정. 입력 위치, 표시 방식, 이 화면에 둘지]

## AI 분석 영역
- 대상: URL·영상·파일·캡처 기록. 메모·하이라이트에는 'AI 분석하기' 버튼이 없다. 챗봇 '기록으로 저장'으로 만든 chat 기록은 처음부터 분석 내용이 있어 버튼이 없다
- 분석 결과 표시: **AI 분석 · mm월 dd일 HH:mm**(analyzed_at), **핵심** 1줄, **요약** 3개 (화면 표기 '핵심 1줄 + 요약 3개'), **함께 볼 만한 기록**(연관 기록), 안내 문구 "AI가 만든 내용이라 틀릴 수 있어요. 메모와는 따로 보관돼요."
- AI 정리글은 핵심 1줄과 요약 3개만 만든다. 파일 내용과 메모(있으면)를 함께 검토하고, 직군별 관점 없이 일반적인 관점으로 쓴다
- AI 분석 글은 **수정할 수 없다**. 옮겨서 고치려면 '메모에 옮기기'를 쓰거나, 분석 글에서 드래그해 직접 복사한다
- 'AI 활용 꺼짐' 그룹(챗봇 설정 '챗봇이 읽지 않을 그룹')의 기록은 'AI 분석하기'·'다시 분석'·'AI 추천'이 비활성이고, 누르면 'AI를 활용한 기록 수집이 꺼져 있는 그룹이에요. 챗봇 설정에서 켤 수 있어요.'

### 버튼과 상태
| 상태 (analysis_status) | 보이는 것 | 버튼 |
| --- | --- | --- |
| 분석 전 (none) | 'AI 분석하기' 버튼만 | **AI 분석하기** |
| 분석 실패 (failed) | '분석하지 못했어요. 잠시 후 다시 시도해 주세요.' | **다시 시도** (AI 분석하기와 같은 요청) |
| 분석 중 (analyzing) | 'AI 분석하기'를 누르면 버튼이 사라지고 'AI 분석' 제목 아래 로딩 표시 | 없음 |
| 분석 완료 (done) | 분석 결과 + 시각 | **다시 분석** · **메모에 옮기기** · **지우기** |

- **AI 분석하기**: 분석을 요청한다. 저장·색인(status)이 끝나지 않았어도 누를 수 있다 (분석 때 글자를 다시 읽는다)
- **AI 분석하기**를 누르면 버튼은 사라지고 분석 중·완료 표시로 바뀐다. 실패하면 실패 안내와 '다시 시도'가 보인다
- **다시 분석**: 마지막 분석 뒤 메모에 **새로 쓴 글자가 10자 이상일 때만 활성** (무한 호출 방지, 2026-11-28 시안 v3). 새로 쓴 글자 수는 지금 메모에서 analyzed_context에 있던 글과 '메모에 옮기기'로 덧붙인 글을 뺀 나머지의 글자 수(공백 제외)다. 비활성일 때 누르면 토스트 '메모에 10자 이상 새로 쓰면 다시 분석할 수 있어요 (지금 n자)' (시안은 n이 0이면 괄호를 붙이지 않음). 서버도 같은 규칙으로 거절한다 (409 ANALYSIS_UNCHANGED)
- **메모에 옮기기**: 요약 3개만 메모 끝에 빈 줄 하나를 두고 `· 요약` 줄로 덧붙이고 자동 저장한다 (핵심 1줄은 옮기지 않음). 같은 분석은 한 번만 옮길 수 있고, 옮긴 뒤 버튼은 비활성. 다시 분석하면 다시 옮길 수 있다. 옮긴 글은 메모에서 고칠 수 있다
- **지우기**: AI 정리글과 요약본 벡터를 지운다 (원문 조각 벡터는 남아 챗봇 검색은 계속된다). 함께 볼 만한 기록도 사라지고, 'AI 분석하기' 버튼이 다시 보인다. 브라우저 확인 창 없이 같은 자리에서 한 번 더 눌러야 지운다 ('한 번 더 누르면 지워요', 화면정의서 F-14). 3초 안에 다시 누르지 않으면 원래대로 돌아간다 (시안 v3)
- 버튼 판단 규칙은 packages/shared `canStartAnalysis`, `canReanalyze`, `canMoveAnalysisToMemo`, 옮길 글은 `memoWithKeyPoints`

## 그룹과 AI 추천
- 그룹 줄: '그룹 이름 · 옮기기'. 기록이 '분류 안 된 기록'에 있을 때만 옆에 'AI 추천' 버튼이 보인다 (F3)
- 'AI 추천'을 누르면 버튼이 'AI 추천 중' + 점 3개로 바뀐다. 결과가 오면 그룹 목록이 펼쳐지고 추천 그룹에 '✦ AI 추천' 뱃지가 붙는다. 자동으로 옮기지 않고 사용자가 골라 옮긴다
- 재료: 자동 가공에서 뽑은 글자, 메모(original_context), 기존 그룹 목록. 기존 그룹 중에서만 고른다
- 알맞은 그룹이 없거나 실패하면 토스트 '알맞은 그룹을 찾지 못했어요. 직접 골라 주세요.'
- 'AI 활용 꺼짐' 그룹의 기록이면 비활성 (위 안내 문구)

## 동작
- 메모를 고친다. 자동 저장된다. 분석이 있는 기록이면 새로 쓴 글자가 10자 이상일 때 '다시 분석'이 활성화된다 ('메모에 옮기기'로 덧붙인 글은 세지 않음)
- 출처 링크가 있으면 원문을 연다
- 그룹을 바꾼다
- 함께 볼 만한 기록을 누른다. 그 기록의 상세로 이동한다. 분석하지 않은 기록에는 보이지 않는다
- 재발견 메모를 남긴다 (P1). 날짜와 함께 쌓이고 이전 메모를 덮어쓰지 않는다는 것만 정해져 있고, 화면 동작은 UI를 정한 뒤 채운다
- 기록을 지운다. 확인 창에서 한 번 더 확인한 뒤 기록 삭제 절차(docs/database.md)대로 DB, Qdrant, Storage에서 모두 지운다. 되돌릴 수 없다

## 확인 필요
- Storage 파일을 보여 주는 방식
- 코드 차이: packages/shared `canReanalyze`는 메모가 analyzed_context와 다르기만 하면 '다시 분석'을 켠다 ('메모에 옮기기' 뒤에도 켜짐). 새로 쓴 글자 10자 이상 규칙(옮긴 글 제외)으로 고쳐야 한다. 웹 API의 409 ANALYSIS_UNCHANGED 판단도 같이 바꾼다 (이번 문서 작업에서는 코드를 고치지 않음)
- 'AI 활용 꺼짐' 그룹의 기록에 이미 있던 AI 분석을 그대로 보여 줄지
