# 수집 캐릭터 (데스크톱)
담당: 데스크톱 · 우선순위: P0 · 요구사항: R2, R3 · 기능: F1, F2, F3

바탕화면에 떠 있는 우주 비행사에 정보를 끌어다 놓아 작업 흐름을 끊지 않고 저장한다.

## 구성 요소
- 우주 비행사 캐릭터: 다른 창 위에 항상 떠 있다
- 끌어다 놓기 영역: 캐릭터 위
- 메뉴: 캐릭터를 누르면 열린다. 클립보드 붙여넣기, 메모, 화면 캡처, 파일선택, 웹 열기, 앱 종료
- 저장 창: 그룹을 고르는 작은 창. 그룹 선택, 'AI 추천' 버튼, 출처 주소 칸(클립보드로 넣은 글일 때, 선택 입력), 저장 버튼
- 저장 결과 표시: 캐릭터 옆에 뜨는 작은 말풍선

| 상황 | 말풍선 문구 | 사라지는 시점 |
| --- | --- | --- |
| 올리는 중 | 받는 중이에요 | 업로드가 끝나면 |
| 업로드 완료 (queued) | 받았어요! 정리하고 있어요 | 2~3초 뒤 |
| 가공 완료 (done) | 정리 끝! 저장했어요 | 2~3초 뒤 |
| 지원하지 않는 형식 | csv, txt, md, jpeg, jpg, png, svg, HTML, PDF 파일만 넣을 수 있어요 | 4~5초 뒤 |
| 10MB 초과 | 10MB보다 큰 파일은 넣을 수 없어요 | 4~5초 뒤 |
| 저장 실패 (네트워크, 서버 오류) | 저장하지 못했어요 + 다시 시도 버튼 | 누르거나 닫을 때까지 |
| 가공 실패 (failed) | 받았지만 정리하지 못했어요. 웹에서 확인해 주세요 | 닫을 때까지 |

## 동작
- 파일이나 이미지(웹페이지 이미지, 바탕화면 파일)를 캐릭터에 놓는다. 형식과 10MB를 검사하고, 통과하면 저장 창을 띄운다
- 브라우저 주소(주소창의 사이트 아이콘이나 페이지 안의 링크)를 캐릭터에 놓는다. URL 기록(유튜브 등은 영상 링크)으로 보고 저장 창을 띄운다. 주소를 복사해 메뉴의 클립보드 붙여넣기로 넣어도 같다
- 저장 창에서 그룹을 정하고 저장한다. 'AI 추천' 버튼을 누르거나, 다른 그룹을 고르거나, 새 그룹을 만들어 저장할 수 있다. 아무것도 고르지 않으면 '분류 안 된 기록'으로 저장한다
  - 저장 창은 '분류 안 된 기록'이 선택된 채로 바로 뜬다. 창이 열릴 때는 AI 추천을 요청하지 않는다
  - 'AI 추천' 버튼을 누르면 웹 서버에 추천을 요청하고, 답이 오면 선택을 추천 그룹으로 바꾼다. 기다리는 동안 버튼에 진행 표시를 하고, 실패하면 선택을 그대로 둔다
  - 버튼 추천에 쓰는 재료는 저장 전에 알 수 있는 것이다: 파일 이름, 주소, 메모나 클립보드 글, 사용자의 그룹 목록
  - '분류 안 된 기록'으로 저장한 기록은 가공이 끝난 뒤 AI가 요약본으로 그룹을 추천한다. 사용자는 웹의 행성 상세 패널에서 수락한다
- 저장하면 기록을 만들고 가공을 요청한다
  - 파일·이미지: Supabase Storage에 올린다
  - URL·영상 링크: 웹 주소를 기록에 저장한다. 가공 서버가 그 주소의 내용을 요약해 기록에 넣는다. 원문 글과 영상 자체는 저장하지 않는다
- 저장한 뒤 앱은 그 기록의 처리 상태를 3초마다 웹 서버에 묻는다. done이나 failed가 되면 말풍선으로 알리고 멈춘다. 2분이 지나도 끝나지 않으면 알리지 않고 멈춘다
- 캐릭터를 눌러 메뉴를 연다
  - 클립보드 붙여넣기: 복사해 둔 글, 이미지, 주소를 저장한다. 글은 저장 창의 출처 주소 칸을 비워도 저장된다 (출처 주소는 모든 기록에서 선택). 출처 주소를 클립보드에서 읽을 수 있으면 미리 채운다
  - 메모: 글을 직접 써서 저장한다
  - 화면 캡처: 화면을 캡처해 저장한다
  - 파일선택: 파일을 골라 저장한다
  - 웹 열기: 브라우저로 Spacelog 웹을 연다
  - 앱 종료: 앱을 끈다
- 메뉴로 넣을 때도 같은 저장 창에서 그룹을 정하고 저장한다
