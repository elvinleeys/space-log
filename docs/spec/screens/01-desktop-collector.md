# 수집 캐릭터 (데스크톱)
담당: 데스크톱 · 우선순위: P0 · 요구사항: R2, R3 · 기능: F1, F2, F3

바탕화면에 떠 있는 우주 비행사에 정보를 끌어다 놓아 작업 흐름을 끊지 않고 저장한다.

## 구성 요소
- 우주 비행사 캐릭터: 다른 창 위에 항상 떠 있다
- 끌어다 놓기 영역: 캐릭터 위
- 메뉴: 캐릭터를 누르면 열린다. 화면 캡처, 메모 [확인 필요: 메뉴 항목 전체]
- 저장 결과 표시 [확인 필요: 표시 방식]

## 동작
- 브라우저에서 드래그해 선택한 글을 캐릭터에 놓는다. 선택한 문장 그대로와 페이지 주소를 하이라이트 기록으로 저장한다
- 브라우저 주소를 놓는다. URL 기록(유튜브 등은 영상 링크)으로 저장하고 가공을 요청한다
- 웹페이지 이미지나 바탕화면 파일을 놓는다. 형식과 10MB를 검사하고 Supabase Storage에 올려 기록을 만든다
- 캐릭터를 눌러 메뉴를 열고 화면 캡처나 메모를 저장한다
- 저장할 때 AI가 추천한 그룹이 기본으로 들어간다

## 확인 필요
- 놓으면 바로 저장할지, 그룹을 고르는 작은 저장 창을 띄울지
- 지원하지 않는 형식이나 10MB를 넘는 파일을 놓았을 때 안내 방식
