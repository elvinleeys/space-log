# 기록 넣기 (웹)
담당: 웹 · 우선순위: P0 · 요구사항: R2, R3 · 기능: F2, F3

메모, 파일, 링크 중 하나만 있으면 저장되는 창에서 분류 부담 없이 기록을 넣는다.

## 구성 요소
- 제목 입력 (선택): 비우면 메모 첫 줄이나 파일 이름을 쓴다
- 메모 입력 (선택): 정보를 접한 맥락이나 저장 이유. 시안 A는 이 칸에 링크를 붙여 넣어도 된다
- 파일 첨부: 파일 고르기 버튼, 끌어다 놓기 (csv, txt, md, jpeg, jpg, png, svg, HTML, PDF, 10MB까지)
- 링크 붙이기 버튼 (시안 B)
- 그룹 선택: 색상 점과 그룹 이름 드롭다운. '분류 안 된 기록'이 기본값
- 'AI 추천' 버튼: 누르면 파일을 먼저 올리고, 가공 서버가 파일 글자와 메모로 기존 그룹 중 하나를 추천해 드롭다운 선택을 바꾼다
- 출처 주소 입력 (선택)
- 저장 버튼: 넣기 (시안 A), 별 띄우기 (시안 B), 취소

## 동작
- 메모, 파일, 링크 중 하나 이상을 넣고 저장한다. 기록을 만들고, 파일은 Supabase Storage에 올린 뒤 가공을 요청한다
- 'AI 추천' 버튼을 누른다. 저장 전이라도 기록을 만들고 파일을 올린 뒤('분류 안 된 기록'), 가공 서버가 파일 글자를 뽑고 메모가 있으면 함께 검토해 기존 그룹 중에서 추천한다. 선택이 추천 그룹으로 바뀌고, 저장을 눌러야 확정된다. 기다리는 동안 버튼에 진행 표시를 하고, 실패하면 선택을 그대로 둔다. 저장하지 않고 창을 닫으면 기록은 '분류 안 된 기록'에 남는다
- 그룹을 고르지 않고 저장한다. '분류 안 된 기록'에 들어가고, 자동 가공(글자 추출)이 끝나면 AI가 뽑은 글자·파일 이름·메모로 그룹을 추천해 '분류 안 된 기록'의 빠른 분류 카드에서 수락할 수 있다
- 드롭다운에서 다른 그룹을 고르거나 새 그룹을 만든다 (새 그룹 이름은 사용자가 직접 정한다)
- Enter로 저장하고 Shift+Enter로 줄을 바꾼다 (시안 A)

## 확인 필요
- AI 추천에 실패했을 때 안내 문구
- 지원하지 않는 형식이나 10MB를 넘는 파일의 안내 방식
