# 행성 상세 패널 (웹)
담당: 웹 · 우선순위: P0 · 요구사항: R3, R5 · 기능: F3, F5, F7

행성(그룹)을 고르면 오른쪽에 열려, 그 그룹의 기록을 기간별로 보고 그룹을 고친다.

## 구성 요소
- 그룹 이름, 기록 수, 이름 변경 버튼, 닫기
- 기간 탭: 오늘, 이번 주, 이번 달, 전체 (탭마다 기록 수)
- 기록 목록: 형식 아이콘, 제목, 넣은 날, 형식·크기 또는 내용 미리보기
- 그룹 편집 메뉴 [확인 필요: 메뉴 항목]

## 동작
- 기간 탭을 고른다. 그 기간에 넣은 기록을 확인한다
- 기록을 고른다. 기록 상세를 연다
- 그룹 이름을 바꾼다
- 빈 그룹을 지운다. 바로 지워진다
- 기록이 있는 그룹을 지운다. '기록을 다른 그룹으로 옮기고 그룹 삭제'와 '기록까지 모두 삭제' 중 하나를 묻고, 고른 대로 진행한다
- '분류 안 된 기록' 패널에서 AI가 기록마다 추천한 그룹을 확인하고 수락하거나 바꾼다

## 확인 필요
- 옮길 그룹을 사용자가 고를지, '분류 안 된 기록'으로 옮길지
- '분류 안 된 기록' 그룹의 이름 변경·삭제 허용 여부
