# F5. 그룹 관리
담당: 웹 · 요구사항: R3

- **입력**: 그룹 이름, 색상, 대상 그룹, 삭제 방식 (기록 옮기기, 기록까지 삭제)
- **처리**: 그룹을 만들고, 이름과 색상을 바꾼다. 빈 그룹은 바로 지운다. 기록이 있는 그룹은 삭제 방식을 묻고, 기록을 다른 그룹으로 옮긴 뒤 그룹을 지우거나 기록까지 모두 지운다
- **출력**: 바뀐 그룹 목록과 우주의 행성
- **예외**: [확인 필요: 옮길 그룹을 고르는 방식] [확인 필요: 기록까지 삭제할 때 함께 지울 범위. 기록 삭제 범위와 같음] [확인 필요: '분류 안 된 기록' 그룹의 이름 변경·삭제 허용 여부] [확인 필요: 같은 이름 그룹 허용 여부] [확인 필요: 색상 지정 방식]
