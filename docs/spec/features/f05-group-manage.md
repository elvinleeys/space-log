# F5. 그룹 관리
담당: 웹 · 요구사항: R3

- **입력**: 그룹 이름, 색상(7가지 중 하나), 모양(5가지 중 하나), 대상 그룹, 삭제 방식 (기록 옮기기, 기록까지 삭제)
- **처리**: 그룹을 만들고, 이름·색상·모양을 바꾸고, 다른 그룹과 합친다. 빈 그룹은 같은 자리에서 한 번 더 눌러 지운다. 기록이 있는 그룹은 삭제 방식을 묻고, 기록을 다른 그룹으로 옮긴 뒤 그룹을 지우거나 기록까지 모두 지운다. 기록을 옮길 때(그룹 삭제, 기록별 그룹 변경 모두) 그 기록들의 Qdrant 벡터 group_id도 함께 갱신한다
- **출력**: 바뀐 그룹 목록 (List 목록 창, Space 행성)
- **예외**: 옮길 그룹은 사용자가 고른다. 기록까지 삭제할 때는 확인 창 후 기록마다 기록 삭제 절차(docs/database.md)를 따른다. '분류 안 된 기록'은 이름 바꾸기·삭제 불가, 같은 이름 그룹 불가, 마지막 그룹은 지울 수 없다 (화면정의서 F-05). [확인 필요: 다른 그룹과 합치기 흐름]
