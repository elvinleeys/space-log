# F1. 구글 로그인
담당: 웹(로그인 페이지, 콜백 이동) + 데스크톱(임시 서버, 토큰 교환) · 요구사항: R1

- **입력**: 구글 계정
- **처리**: Supabase 인증의 구글 로그인으로 사용자를 확인한다. 처음 로그인한 사용자면 사용자와 기본 그룹 '분류 안 된 기록'을 만든다. 데스크톱 앱은 로컬 주소로 돌려받기(loopback)와 PKCE로 토큰을 받는다
- **출력**: 데스크톱 앱과 웹에서 같이 쓰는 로그인 상태
- **예외**: [확인 필요: 로그인 실패 처리] [확인 필요: 데스크톱 앱에서 브라우저 로그인을 끝내지 않고 닫았을 때 임시 서버 처리]
