# F1. 로그인 (이메일, Google)
담당: 웹 + 데스크톱 · 요구사항: R1

- **입력**: 이메일과 비밀번호, 또는 Google 계정
- **처리**: Supabase 인증으로 사용자를 확인한다. 이메일 가입·로그인과 Google 가입·로그인을 모두 받는다. 처음 로그인한 사용자면 사용자와 기본 그룹 '분류 안 된 기록'을 만든다. Google 계정이면 이름·프로필 사진·이메일을 app_user 테이블에 복사한다. 인증 정보가 바뀌면 프로필 사진과 이메일만 다시 복사하고, 표시 이름은 사용자가 바꿀 수 있으므로 덮어쓰지 않는다. 이메일 계정은 'Google 연동'으로 Google 계정을 연결할 수 있다 (Supabase 계정 연결). Google로 로그인한 계정에는 연동이 없다. 같은 이메일은 Supabase 기본 동작대로 묶는다. 데스크톱 앱은 로컬 주소로 돌려받기(loopback)와 PKCE로 토큰을 받는다
- **출력**: 데스크톱 앱과 웹에서 같이 쓰는 로그인 상태
- **예외**: [확인 필요: 로그인 실패 처리] [확인 필요: 데스크톱 앱에서 브라우저 로그인을 끝내지 않고 닫았을 때 임시 서버 처리] [확인 필요: 이메일 인증 메일 확인 여부, 비밀번호 찾기]
