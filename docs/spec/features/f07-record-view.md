# F7. 기록 조회
담당: 웹 · 요구사항: R5

- **입력**: 조회할 정보 기록
- **처리**: 정보 내용, 원래 맥락, AI 정리글, 원문 링크, 파일, 재발견 메모를 불러온다. 연관 기록은 이 기록의 요약본 벡터로 Qdrant를 검색해 유사도 0.8 이상 중 상위 3개를 링크로 붙인다 (자기 자신 제외, 없거나 deleting인 기록 제외)
- **출력**: 다시 확인할 수 있는 정보 기록
- **예외**: status가 deleting이면 지워진 기록으로 본다. [확인 필요: 기록이 없거나 지워졌을 때 화면 안내] [확인 필요: Storage 파일을 보여 주는 방식. 공개 주소, 기한이 있는 서명 주소]
