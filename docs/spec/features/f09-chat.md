# F9. AI 챗봇 답변
담당: 웹 (Next.js 서버) · 요구사항: R6

- **입력**: 사용자 질문, 분석 요청(기간·그룹 묶음 또는 기록 하나), AI 추천 버튼, FAQ 선택
- **처리**: Next.js 서버가 질문을 벡터로 바꿔 Qdrant에서 이 사용자의 요약본·원문 조각 벡터 중 가까운 것을 찾는다 (user_id 필터 필수). 챗봇·MCP 검색 제외로 설정된 그룹의 기록과 status가 deleting인 기록은 결과에서 뺀다. 검색할 때 제외 그룹 id 목록을 조건으로 넘겨 Qdrant payload의 group_id로 거른다. 질문 벡터는 가공 서버(FastAPI)와 같은 임베딩 모델로 만든다. 찾은 기록을 Supabase DB에서 불러와 요약본, 하이라이트 문장, 메모 글로 AI API가 답을 만들고, 근거 기록을 함께 돌려준다. URL·영상 링크의 원문 글은 저장하지 않으므로 답변에 쓰지 않는다
- **분석 요청**: 묶음 분석(예: '이번 주 기록 분석해줘')은 기간·그룹의 기록을 그룹별로 정리해 답하고 각 기록에는 저장하지 않는다. 기록 하나 분석은 F4의 AI 분석과 같고 그 기록의 AI 분석 칸에 저장한다(다시 분석 규칙 동일)
- **기록으로 저장**: 분석 답변을 chat 기록(record_type chat, collected_from web, 그룹 '분류 안 된 기록')으로 저장한다. 답변은 summary·summary_detail에, 근거 기록 id는 summary_detail.sources에 둔다. analysis_status는 done이라 'AI 분석하기' 버튼이 없다
- **AI 추천**: '분류 안 된 기록'의 그룹 추천을 요청한다 (F3)
- **출력**: 답변, 근거 기록 목록 (그룹, 제목), 분석 답변의 '크게 보기'·'기록으로 저장'
- **예외**: 관련 기록이 없으면 찾지 못했다고 답한다. [확인 필요: 관련 기록이 제외 그룹에만 있을 때 '제외한 그룹은 찾지 않았다'고 알려 줄지] [확인 필요: 사용법 질문 처리] [확인 필요: 처리 중인 기록을 답변에 포함할지] [확인 필요: FAQ 목록과 문구] [확인 필요: 기록으로 저장하는 API와 chat 기록의 제목] [확인 필요: Storage에 원본이 있는 파일의 원문 조각 글을 답변에 쓸지]
