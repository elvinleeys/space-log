# F9. AI 챗봇 답변
담당: 웹 (Next.js 서버) · 요구사항: R6

- **입력**: 사용자 질문
- **처리**: Next.js 서버가 질문을 벡터로 바꿔 Qdrant에서 이 사용자의 요약본·원문 조각 벡터 중 가까운 것을 찾는다 (user_id 필터 필수). 챗봇·MCP 검색 제외로 설정된 그룹의 기록과 status가 deleting인 기록은 결과에서 뺀다. 검색할 때 제외 그룹 id 목록을 조건으로 넘겨 Qdrant payload의 group_id로 거른다. 질문 벡터는 가공 서버(FastAPI)와 같은 임베딩 모델로 만든다. 찾은 기록을 Supabase DB에서 불러와 요약본, 하이라이트 문장, 메모 글로 AI API가 답을 만들고, 근거 기록을 함께 돌려준다. URL·영상 링크의 원문 글은 저장하지 않으므로 답변에 쓰지 않는다
- **출력**: 답변, 근거 기록 목록 (그룹, 제목)
- **예외**: 관련 기록이 없으면 찾지 못했다고 답한다. [확인 필요: 관련 기록이 제외 그룹에만 있을 때 '제외한 그룹은 찾지 않았다'고 알려 줄지] [확인 필요: 사용법 질문 처리] [확인 필요: 처리 중인 기록을 답변에 포함할지] [확인 필요: Storage에 원본이 있는 파일의 원문 조각 글을 답변에 쓸지]
