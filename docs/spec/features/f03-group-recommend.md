# F3. AI 그룹 추천
담당: 웹 · 요구사항: R3

- **입력**: 기록 내용, 사용자의 그룹 목록
- **처리**: 기존 그룹 중 기록에 어울리는 그룹을 골라 기본값으로 넣는다. 사용자가 새 그룹을 만들 때는 그룹 이름을 추천한다. 추천 결과는 suggested_group_id에도 남긴다
- **출력**: 미리 선택된 추천 그룹, 추천 그룹 이름
- **예외**: 추천이 없거나 실패하면 '분류 안 된 기록'에 넣는다. [확인 필요: 추천 시점. 저장 창이 열릴 때, 가공이 끝난 뒤] [확인 필요: 처리 위치. 웹 서버, 가공 서버(FastAPI)] [확인 필요: 새 그룹 이름 추천에 쓰는 입력]
