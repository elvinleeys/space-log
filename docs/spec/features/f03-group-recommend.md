# F3. AI 그룹 추천
담당: 웹 · 요구사항: R3

AI 그룹 추천은 기존 그룹 중에서만 고르고, 기록을 자동으로 옮기지 않는다. 세 시점에 일어난다. '분류 안 된 기록'으로 저장한 기록의 자동 가공(글자 추출)이 끝났을 때, 기록 상세에서 'AI 추천' 버튼을 누를 때, 챗봇 FAQ '분류 안 된 기록 정리해줘'를 물을 때다. 저장 창(데스크톱·웹 기록 넣기)에는 AI 추천이 없다 (2026-11-28, 시안 v3). AI 분석(AI 정리글)과는 상관없이 동작한다.

**버튼 추천 (기록 상세)**
- **입력**: 자동 가공에서 뽑은 글자(URL·영상은 원문에서 뽑은 글자), 메모(original_context, 있으면), 사용자의 기존 그룹 목록
- **처리**: 기록이 '분류 안 된 기록'에 있을 때만 그룹 줄에 'AI 추천' 버튼이 보인다. 누르면 버튼이 'AI 추천 중' + 점 3개로 바뀌고, 기존 그룹 중 어울리는 그룹을 고른다. 새 그룹은 만들지 않는다
- **출력**: 그룹 목록이 펼쳐지고 추천 그룹에 '✦ AI 추천' 뱃지가 붙는다. suggested_group_id에도 남긴다. 자동으로 옮기지 않고 사용자가 골라 옮긴다
- **예외**: 알맞은 그룹이 없거나 실패하면 토스트 '알맞은 그룹을 찾지 못했어요. 직접 골라 주세요.' 'AI 활용 꺼짐' 그룹(ai_search_excluded)의 기록이면 버튼 비활성 + 'AI를 활용한 기록 수집이 꺼져 있는 그룹이에요. 챗봇 설정에서 켤 수 있어요.' [확인 필요: 자동 가공이 끝나지 않아 뽑은 글자가 없을 때 처리 (메모·파일 이름만으로 추천, 가공이 끝날 때까지 비활성)]

**가공 후 추천 ('분류 안 된 기록')**
- **입력**: 자동 가공에서 뽑은 글자, 파일 이름, 메모(original_context), 사용자의 그룹 목록 (AI 정리글은 버튼을 눌러야 생기므로 쓰지 않는다)
- **처리**: 기록이 아직 '분류 안 된 기록'에 있으면 어울리는 그룹을 골라 suggested_group_id에 남긴다. 그룹을 자동으로 옮기지는 않는다
- **출력**: '분류 안 된 기록'의 빠른 분류 카드(화면정의서 F-08)에서 기록마다 추천 그룹 표시, 사용자가 수락하거나 바꿈
- **예외**: 추천이 없으면 표시하지 않는다. 처리 위치는 가공 서버 (가공 끝에 추천)

**챗봇 AI 추천**
- **입력**: '분류 안 된 기록'에 있는 기록들, 사용자의 그룹 목록
- **처리**: 챗봇 FAQ의 '분류 안 된 기록 정리해줘'(또는 같은 뜻의 질문)로 요청하면 기록마다 어울리는 기존 그룹을 골라 suggested_group_id에 남긴다. 자동으로 옮기지 않는다
- **출력**: 대화창 답에 '기록 → 추천 그룹' 목록. 수락은 '분류 안 된 기록'의 빠른 분류 카드에서 한다

새 그룹 이름 추천은 하지 않는다 (2026-11-28).

**PRD와 다른 점**: PRD 원칙 1은 추천 그룹이 "미리 선택"되어 있다고 한다. 지금은 가공 후 추천과 기록 상세 버튼 추천만 있고, 저장 창에서 미리 선택하지 않는다. [확인 필요: PRD 작성자 합의]
