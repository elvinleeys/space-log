# F3. AI 그룹 추천
담당: 웹 · 요구사항: R3

AI 그룹 추천은 기존 그룹 중에서만 고르고, 기록을 자동으로 옮기지 않는다. 세 시점에 일어난다. 저장 창에서 사용자가 버튼을 누를 때, '분류 안 된 기록'으로 저장한 기록의 자동 가공(글자 추출)이 끝났을 때, 챗봇의 'AI 추천' 버튼을 누를 때다. 저장 창이 열릴 때 자동으로 추천하지 않는다. AI 분석(AI 정리글)과는 상관없이 동작한다.

**버튼 추천 (저장 창)**
- **입력**: 가공 서버가 파일에서 뽑은 글자(URL·영상은 원문에서 뽑은 글자), 메모(original_context, 있으면), 사용자의 기존 그룹 목록
- **처리**: 사용자가 'AI 추천' 버튼을 누르면 저장 전이라도 먼저 기록을 만들고 파일을 올린다 (수집 흐름 1~3단계, '분류 안 된 기록'). 가공 서버가 글자를 뽑고, 메모가 있으면 함께 검토해 기존 그룹 중 어울리는 그룹을 고른다. 새 그룹은 만들지 않는다
- **출력**: 저장 창의 그룹 선택이 추천 그룹으로 바뀜. suggested_group_id에도 남긴다. 그룹은 사용자가 저장을 눌러야 확정된다 (이미 만든 기록의 group_id를 바꾼다)
- **예외**: 기다리는 동안 버튼에 진행 표시. 실패하면 선택을 그대로 둔다. 저장하지 않고 창을 닫으면 기록은 '분류 안 된 기록'에 남는다. [확인 필요: 실패 안내 문구]

**가공 후 추천 ('분류 안 된 기록')**
- **입력**: 자동 가공에서 뽑은 글자, 파일 이름, 메모(original_context), 사용자의 그룹 목록 (AI 정리글은 버튼을 눌러야 생기므로 쓰지 않는다)
- **처리**: 기록이 아직 '분류 안 된 기록'에 있으면 어울리는 그룹을 골라 suggested_group_id에 남긴다. 그룹을 자동으로 옮기지는 않는다
- **출력**: '분류 안 된 기록'의 빠른 분류 카드(화면정의서 F-08)에서 기록마다 추천 그룹 표시, 사용자가 수락하거나 바꿈
- **예외**: 추천이 없으면 표시하지 않는다. 처리 위치는 가공 서버 (가공 끝에 추천)

**챗봇 AI 추천**
- **입력**: '분류 안 된 기록'에 있는 기록들, 사용자의 그룹 목록
- **처리**: 챗봇 FAQ의 '분류 안 된 기록 정리해줘'(또는 같은 뜻의 질문)로 요청하면 기록마다 어울리는 기존 그룹을 골라 suggested_group_id에 남긴다. 자동으로 옮기지 않는다
- **출력**: 대화창 답에 '기록 → 추천 그룹' 목록. 수락은 '분류 안 된 기록'의 빠른 분류 카드에서 한다

새 그룹 이름 추천은 하지 않는다 (2026-11-28).

**PRD와 다른 점**: PRD 원칙 1은 추천 그룹이 "미리 선택"되어 있다고 한다. 버튼 방식은 사용자가 누를 때만 추천한다. [확인 필요: PRD 작성자 합의]
