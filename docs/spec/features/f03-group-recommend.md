# F3. AI 그룹 추천
담당: 웹 · 요구사항: R3

AI 그룹 추천은 세 시점에 일어난다. 저장 창에서 사용자가 버튼을 누를 때, '분류 안 된 기록'으로 저장한 기록의 자동 가공(글자 추출)이 끝났을 때, 챗봇의 'AI 추천' 버튼을 누를 때다. 저장 창이 열릴 때 자동으로 추천하지 않는다. AI 분석(AI 정리글)과는 상관없이 동작한다.

**버튼 추천 (저장 창)**
- **입력**: 저장 전에 알 수 있는 재료 (파일 이름, 주소, 메모나 클립보드 글), 사용자의 그룹 목록
- **처리**: 사용자가 'AI 추천' 버튼을 누르면 기존 그룹 중 어울리는 그룹을 고른다
- **출력**: 저장 창의 그룹 선택이 추천 그룹으로 바뀜. suggested_group_id에도 남긴다
- **예외**: 실패하면 선택을 그대로 둔다. [확인 필요: 처리 위치. 창이 떠 있는 동안 바로 답해야 하므로 웹 서버 API로 할지] [확인 필요: 실패 안내 문구]

**가공 후 추천 ('분류 안 된 기록')**
- **입력**: 자동 가공에서 뽑은 글자, 파일 이름, 메모(original_context), 사용자의 그룹 목록 (AI 정리글은 버튼을 눌러야 생기므로 쓰지 않는다)
- **처리**: 기록이 아직 '분류 안 된 기록'에 있으면 어울리는 그룹을 골라 suggested_group_id에 남긴다. 그룹을 자동으로 옮기지는 않는다
- **출력**: 행성 상세 패널의 '분류 안 된 기록'에서 기록마다 추천 그룹 표시, 사용자가 수락하거나 바꿈
- **예외**: 추천이 없으면 표시하지 않는다. [확인 필요: 처리 위치. 가공 서버가 가공 끝에 할지]

**챗봇 AI 추천**
- **입력**: '분류 안 된 기록'에 있는 기록들, 사용자의 그룹 목록
- **처리**: 챗봇의 'AI 추천' 버튼을 누르면 기록마다 어울리는 그룹을 골라 suggested_group_id에 남긴다. 자동으로 옮기지 않는다
- **출력**: 추천 결과 [확인 필요: 챗봇 안에서 보여 주고 바로 수락할지, 행성 패널로 보낼지]

**새 그룹 이름 추천**
- 사용자가 새 그룹을 만들 때 AI가 그룹 이름을 추천하고, 사용자가 고쳐서 만든다. [확인 필요: 이름 추천에 쓰는 입력]

**PRD와 다른 점**: PRD 원칙 1은 추천 그룹이 "미리 선택"되어 있다고 한다. 버튼 방식은 사용자가 누를 때만 추천한다. [확인 필요: PRD 작성자 합의]
