# 결정 기록

구조나 기술을 바꾸기 전에 아래 결정과 이유를 먼저 확인한다. 바꾸게 되면 새 줄을 추가하고 기존 줄은 지우지 않는다.

| 날짜 | 결정 | 이유 |
| --- | --- | --- |
| 2026-11-26 | npm workspaces 모노레포 (apps/desktop, apps/web, apps/worker, packages/*) | 데스크톱·웹이 타입과 수집 함수를 함께 쓰기 위해 |
| 2026-11-26 | 데스크톱 앱은 수집 전용, 웹은 수집 + 찾기 | 데스크톱은 작업 중 빠른 저장에 집중 |
| 2026-11-26 | 가공은 Flask 서버 (apps/worker) | Python 문서 처리·OCR 도구 활용, 서버리스 실행 시간 제한 회피 |
| 2026-11-26 | 웹 서버 API가 Flask에 가공 요청 전달 + Flask 주기적 재처리 | 입구를 하나로 유지, 전달 누락 복구 |
| 2026-11-26 | 일반 데이터는 Supabase DB, 원본 파일은 Supabase Storage, 벡터는 Qdrant | DB 용량을 메타데이터에 쓰고 벡터 용량 여유 확보 |
| 2026-11-26 | Supabase DB가 기준, Qdrant는 재생성 가능한 색인 | Qdrant 무료 클러스터는 오래 안 쓰면 삭제될 수 있음 |
| 2026-11-26 | Supabase 인증의 구글 로그인 | 팀 결정 |
| 2026-11-26 | 데스크톱 로그인은 로컬 주소로 돌려받기 + PKCE | 팀 결정 |
| 2026-11-26 | 지원 파일: csv, txt, md, jpeg, jpg, png, svg, HTML, PDF. 이미지는 OCR, 영상 링크는 자막·음성을 글로 변환 | 팀 결정 |
| 2026-11-26 | 파일 1개 10MB 제한 | Storage 무료 용량 1GB를 조직이 공유, 큰 파일은 가공 시간·AI 비용 증가 |
| 2026-11-26 | 업로드 원본 파일은 가공 후에도 유지 | 벡터로 원본을 되살릴 수 없음. 미리보기·재가공·Qdrant 재생성에 필요 |
| 2026-11-26 | URL·영상 링크 원문 글은 저장하지 않음 (A안). 원문 조각 벡터는 관련 기록 찾기용 | PRD 4-5 원칙, 무료 용량. 원문 조각 글 DB 저장(C안)은 고도화 항목 |
| 2026-11-26 | 요약본 벡터 + 원문 조각 벡터를 모두 Qdrant에 저장 | 요약으로 대략 찾고, 원문 조각으로 세부 내용이 있는 기록을 찾기 위해 |
| 2026-11-26 | 챗봇은 Next.js 서버에서 처리 | 응답 속도 기대 |
| 2026-11-26 | 그룹은 별도 테이블, 기록은 그룹 하나를 참조 | 이름 변경, 행성 색상, 빈 그룹 생성 지원 |
| 2026-11-26 | AI가 기존 그룹을 추천해 기본값으로, 새 그룹 이름도 추천. 사용자가 변경 가능 | PRD 원칙 1, 팀 결정 |
